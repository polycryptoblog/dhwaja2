#!/usr/bin/env node
/**
 * Harvest the siblings a room named and nobody read.
 *
 * WHY THIS EXISTS, and what it cost to find out. ANTI-018 settles that ownership
 * decides who fixes a defect, never whether the defect exists: a room that finds
 * the same shape in a file it does not own REPORTS it instead of reaching for it.
 * Rooms do that, correctly and often, in the only place they have — a comment in
 * the file they do own. Until this script, nothing downstream read those
 * sentences. The report was written, committed, and dropped on the floor.
 *
 * The worked example, by name, because a reader six months from now needs to know
 * this was built from a live credential exposure and not from a theory.
 * `services/trust-core/src/checkpoint.ts:428-435` (added in S-035, commit 24fea77)
 * fixes a redirect-follow defect on its signer hop and says, in the same comment:
 *
 *     MANUAL REDIRECTS (SA-03). `fetch`'s default ("follow") resends this
 *     request's `authorization` header — the signer bearer token — at whatever
 *     host a 3xx names … (SA-03 also names registry-sign.ts's copy of this hop;
 *     that file is a different room's ownership and is not touched here.)
 *
 * `services/trust-core/src/registry-sign.ts:448-456` still sends
 * `authorization: Bearer ${cfg.token}` with no `redirect` option. A bearer token
 * that follows a 3xx is a credential handed to whoever controls the redirect.
 * The room named the file, in writing, in the same change, and the sentence sat
 * unread from 2026-09-13 until a human happened to notice it — that is QUEUE #213,
 * and this script is QUEUE #214, the mechanism that should have caught it the day
 * it was written.
 *
 * PRECISION IS THE WHOLE POINT, and the org has already paid to learn why. The
 * harness leg is advisory and its red count meaningless because 36 of 97 pinned
 * harnesses are unplaced; nobody reads a number that is mostly noise. QUEUE #215
 * states the same caveat in advance: "a blanket grep for siblings over a service
 * this size is noisy, and a noisy check is ignored". So every rule below narrows,
 * and each one is here because a wider version demonstrably produces garbage:
 *
 *  1. ADDED LINES ONLY. Context and removed lines are not a report; they are the
 *     state before the room spoke. The reference must sit on a `+` line.
 *  2. COMMENTS ONLY. A path inside an `import` is a DEPENDENCY, not a report —
 *     and dependencies are the overwhelming majority of file-to-file references
 *     in this tree, so admitting them alone would sink the signal. Comments are
 *     extracted by a real per-language scanner that tracks string literals and
 *     `/* *\/` nesting, not by a line-prefix test: `const u = "https://x"` must
 *     not read as a `//` comment. `//` for TS/JS/Kotlin/Swift, `--` for SQL, `#`
 *     for YAML/shell/TOML, plus block comments and their `*` continuation lines.
 *     Markdown is deliberately NOT scanned — `org/**` is full of fenced code and
 *     would supply thousands of references that are records, not reports.
 *  3. THE REFERENCE MUST RESOLVE TO A REAL FILE. Literal path first, then a
 *     basename lookup when exactly one file in the tree carries that name. This
 *     is `scripts/intake/make-wave.mjs`'s resolver and its extension list,
 *     reused rather than re-invented: S-067's whole lesson was that a second,
 *     narrower copy of a resolution rule silently drops a population (42 native
 *     client rows, for the length of the entire register). A `.kt` or `.swift`
 *     sibling must resolve here for the same reason it must resolve there.
 *  4. NO SELF-REFERENCES. A file naming itself is not a sibling. A file naming
 *     its own test (same stem, one side a `.test`/`.spec` file) is not a sibling
 *     either — that is a room pointing at its own guard. Stem equality ACROSS
 *     that test boundary only: `apps/web/src/views.ts` naming
 *     `apps/creator-console/src/views.ts` is exactly the case this check is for,
 *     and a naive stem match would have deleted it.
 *  5. NO TRIVIALLY CO-CHANGED FILES. If the referenced file was modified in the
 *     same diff, the room already handled it and the comment is a cross-link,
 *     not a handoff. The count of drops for this reason is PRINTED, always: it is
 *     the number that shows the check is discriminating rather than listing. A
 *     wide `--range` weakens this filter (a net diff over 70 commits calls
 *     everything co-changed), which is why `--per-commit` exists.
 *
 * RANK, DON'T JUST LIST. A hit is only worth a human's attention if the comment
 * carries the language of DEFERRAL — the room saying it saw the thing and could
 * not reach it. The signal table below is keyed on the three ways rooms in this
 * tree actually write that, drawn from reading the comments they wrote:
 *   (A) ownership — "not touched here", "different room", "room's ownership",
 *       "out of scope", "owns X only". This is ANTI-018 being obeyed out loud
 *       and it is the strongest possible evidence, because the room is stating
 *       the defect exists AND that it is not the one to fix it.
 *   (B) duplication — "copy of this", "'s copy", "same shape", "sibling",
 *       "mirrors", "duplicated rather than imported". The room is asserting the
 *       two files carry one shape, which is the premise QUEUE #215 generalises.
 *   (C) state — "known gap", "not fixed", "unfixed", "still", "follow-up",
 *       "reported", "TODO". Weaker on its own ("still" is a common word), which
 *       is why it is weighted low and why the score is a SUM: one C-word alone
 *       never clears the threshold, a C-word beside an A-word always does.
 * Scoring is over the whole enclosing comment BLOCK, not the single added line,
 * because the room's deferral sentence and its filename routinely land on
 * different lines — in checkpoint.ts the filename is on one line and "is not
 * touched here" two lines below it. Scoring the line alone scores that case zero.
 *
 * WHAT IT MEASURED, on the tree it was built against, so the next person does not
 * have to take the precision claim on faith. `f2a5db1..HEAD` (75 commits,
 * `--per-commit`, threshold 6): 1,298,427 added lines, 37,429 of them comments in
 * a scannable language, 3,214 file references inside those comments, and after
 * the five filters — 740 unresolved, 147 self, 1,208 co-changed — 855 surviving
 * pairs grouped into 680 comments, of which 14 cleared the threshold. Of those
 * 14, SIX were true (five distinct defects) and EIGHT were false. One batch alone
 * (S-035, `24fea77`, 370 files) produced six candidates, four of them true,
 * including QUEUE #213 at score 18 — more than double the next-highest hit in the
 * entire history, which is the shape you want: the one that mattered was not a
 * marginal call.
 *
 * The threshold is 6 because the distribution has a cliff there: 113 candidates at
 * >=3, 63 at >=4, 48 at >=5, 14 at >=6. Six is also the lowest score that CANNOT
 * be reached by one signal alone — it takes an ownership phrase plus anything, or
 * two independent duplication/state phrases. A bare "still" or a bare "sibling"
 * never clears it, and the 48-at-5 band is almost entirely rooms citing a
 * precedent or an invariant, which is not a handoff.
 *
 * EXIT CODE. Zero by default, non-zero only under `--strict`. The default is
 * advisory ON PURPOSE, on the numbers above: a hit here is a CANDIDATE, and eight
 * of fourteen were wrong in ways no amount of regex tightening fixes. Three were
 * MISTARGETED — the comment defers something real and the regex lifts the wrong
 * filename out of it. One was STALE, and staleness is structural rather than a
 * bug: comments do not get retracted. `ratings.ts:842` calls a wiring change "a
 * one-line follow-up outside this room's ownership"; S-070 did it at
 * `index.ts:3874` and nobody edited the comment. registry-sign.ts's own comment is
 * the same failure in mirror image — it says checkpoint.ts "still measures after
 * the read", which stopped being true the day checkpoint.ts was fixed. A leg that
 * blocks a green batch on a sentence about a world that has moved on teaches
 * everyone to route around it, and this org already has one advisory-because-noisy
 * leg (`--harnesses`, 36 of 97 pinned harnesses unplaced) whose red count has been
 * meaningless for months. Blocking belongs in a deliberate sweep, where somebody
 * is present to read the rows.
 *
 * Usage:
 *   node scripts/harvest-siblings.mjs                      # working tree vs HEAD
 *   node scripts/harvest-siblings.mjs --range=a36e360..HEAD
 *   node scripts/harvest-siblings.mjs --range=f2a5db1..HEAD --per-commit
 *   node scripts/harvest-siblings.mjs --out=reports/sib.md --min-score=6 --strict
 *   node scripts/harvest-siblings.mjs --range=HEAD --include-untracked   # + untracked, not-ignored files as wholly added
 *
 * --include-untracked (S-074 J74-03): W2 syncs NEW files into the repo uncommitted, and `git diff` cannot see
 * untracked files, so every sibling a room named from a new file was invisible. With the flag, each untracked,
 * not-ignored regular file (`git ls-files --others --exclude-standard`) is scanned as if every line were added.
 * Read-only: no `git add -N`. Only valid when the diff ends at the working tree (no `..` range, no --per-commit).
 *
 * --shape=<commit-or-range> (D-0419 / QUEUE #215, ANTI-021's second clause): a SEPARATE mode, run instead of
 * the comment-harvest above. For each hunk in the given single commit (`git show`) or two-dot range (`git diff`),
 * extracts distinctive tokens straight from the CODE — identifiers >=6 chars, quoted object/lookup keys, SQL
 * statement openers — keeps only tokens that occur in <=20 tracked files repo-wide (the same "noisy check is
 * ignored" caveat this file already carries, applied to tokens instead of signal phrases), and lists every OTHER
 * tracked file that independently carries >=2 of them as a SIBLINGS table (path, shared tokens, count). No
 * comment, no deferral sentence, no SIGNALS table involved — this is the case nobody wrote anything down.
 *   node scripts/harvest-siblings.mjs --shape=a238ce1..884915a --out=org/07-findings/<run>/<room>/SIBLINGS.md
 *   node scripts/harvest-siblings.mjs --shape=24fea77 --out=org/07-findings/S-079-batch/SIBLINGS/shape-24fea77.md
 *
 * A ROOM's candidate is its UNCOMMITTED WORKING TREE and B1 forbids it the commit that would give

// ------------------------------------------------------------------ language
// Only languages whose comment syntax can be scanned without guessing. Adding a
// language here is a deliberate act: an over-broad list is how a precise check
// becomes a grep.
const LANGS = {
  ts: { line: "//", block: true }, tsx: { line: "//", block: true },
  js: { line: "//", block: true }, jsx: { line: "//", block: true },
  mjs: { line: "//", block: true }, cjs: { line: "//", block: true },
  kt: { line: "//", block: true }, kts: { line: "//", block: true },
  swift: { line: "//", block: true },
  sql: { line: "--", block: true },
  yml: { line: "#", block: false }, yaml: { line: "#", block: false },
  sh: { line: "#", block: false }, bash: { line: "#", block: false },
  toml: { line: "#", block: false },
};
const langOf = (p) => LANGS[p.slice(p.lastIndexOf(".") + 1).toLowerCase()] ?? null;

/**
 * The comment text of every line, or "" for a line that carries none. A real
 * scanner and not a prefix test, because `const u = "https://ex"` and
 * `const re = /a--b/` are not comments and a prefix test says they are.
 * Under-detection is the safe direction here and the failure modes (a `//`
 * inside a `${}` interpolation, a regex literal containing the line token) all
 * fall that way.
 */
function commentsOf(lines, lang) {
  const out = new Array(lines.length).fill("");
  let inBlock = false;
  for (let i = 0; i < lines.length; i++) {
    const s = lines[i];
    let buf = "";
    let j = 0;
    let q = null;
    while (j < s.length) {
      if (inBlock) {
        const end = s.indexOf("*/", j);
        if (end === -1) { buf += s.slice(j); j = s.length; } else { buf += s.slice(j, end); j = end + 2; inBlock = false; }
        continue;
      }
      const c = s[j];
      if (q) {
        if (c === "\\") { j += 2; continue; }
        if (c === q) q = null;
        j++; continue;
      }
      if (c === '"' || c === "'" || (lang.line === "//" && c === "`")) { q = c; j++; continue; }
      if (lang.block && c === "/" && s[j + 1] === "*") { inBlock = true; j += 2; continue; }
      if (s.startsWith(lang.line, j)) { buf += s.slice(j + lang.line.length); j = s.length; continue; }
      j++;
    }
    out[i] = buf.replace(/^\s*\*+/, " ").trim();
  }
  return out;
}

const EXT_G = /`?([A-Za-z0-9_][A-Za-z0-9_./-]*\.(?:ts|tsx|sql|mjs|js|kt|kts|swift))/g;
// I3-0874: "org" added -- it holds scratch copies of product source (harness/ records,
// patches/), so without this the basename index carried TWO candidates for the same file
// (the real one under services/apps/packages and the org/ scratch copy), leaving every such

const SKIP_DIRS = new Set(["node_modules", ".git", "dist", "build", ".wrangler", ".stryker-tmp", "deliverables", "org"]);
let BASENAMES = null;
const byBasename = (p) => {
  if (!BASENAMES) {
    BASENAMES = new Map();
    const walk = (dir) => {
      for (const e of readdirSync(dir, { withFileTypes: true })) {
        if (SKIP_DIRS.has(e.name)) continue;
        const full = `${dir}/${e.name}`;
        if (e.isDirectory()) walk(full);
        else {
          if (!BASENAMES.has(e.name)) BASENAMES.set(e.name, []);
          BASENAMES.get(e.name).push(full.replace(/^\.\//, ""));
        }
      }
    };
    walk(".");
  }
  const hits = BASENAMES.get(p.split("/").pop()) ?? [];
  return hits.length === 1 ? hits[0] : null;
};
const resolve = (raw) => {
  const clean = raw.replace(/^\.\//, "");
  if (existsSync(clean) && langOf(clean)) return clean;
  return byBasename(clean);
};

  const byKey = new Map();
  for (const r of triage.rows) { byKey.set(`${r.id}@${r.source}`, r); if (!byKey.has(r.id)) byKey.set(r.id, r); }
  const EXT1 = /`?([A-Za-z0-9_][A-Za-z0-9_./-]*\.(?:ts|tsx|sql|mjs|js|kt|kts|swift))/;
  const fileOf = (r) => {
    if (r.resolved && existsSync(r.resolved)) return r.resolved;
    const raw = (r.location || "").match(EXT1)?.[1] ?? null;
    if (!raw) return null;
    return existsSync(raw) ? raw : byBasename(raw);
  };
  for (const [key, e] of Object.entries(closed)) {
    const row = byKey.get(key) ?? byKey.get(key.split("@")[0]);
    if (!row) continue;
    const f = fileOf(row);
    if (!f) continue;
    if (!idx.has(f)) idx.set(f, { total: 0, real: 0, overturned: 0 });
    const rec = idx.get(f);
    rec.total++;
    if (/REAL/i.test(e.verdict ?? "")) rec.real++;
    const j = e.judge ?? e.judge_unattributed;
    if (j?.ruling === "OVERTURNED") rec.overturned++;
  }
  return { idx, present: true };
}

// ------------------------------------------------------------------- shape
// D-0419 / QUEUE #215, second half. ANTI-021's first clause is about a CLAIM: a
// field or flag described as meaning more than it does, and the fix owes every
// surface that renders it. The comment-harvest above (COMMENTS ONLY, rule 2)
// finds that: siblings a room named in writing. This mode is the other half --
// a SHAPE (a redirect posture, a guard predicate, an ordering key) has no
// sentence to grep for, so the only evidence left is the code itself. Scoped
// to the changed hunk's own tokens on purpose (QUEUE #215's own caveat: "a
// blanket grep for siblings over a service this size is noisy, and a noisy
// check is ignored") -- never a repo-wide grep for a word the hunk happens to
// contain.
//
// A token is DISTINCTIVE only if it is rare: present in the hunk and in at
// most 20 tracked files repo-wide. A common identifier clears that bar in the
// wrong direction and is dropped before any file is scored -- the same
// precision-over-recall stance as MIN_SCORE above, applied to tokens instead
// of signal phrases. A file only lands in the SIBLINGS table if it
// independently carries at least two of the hunk's rare tokens: one shared
// word is coincidence, two is a shape.
function parseHunksForShape(diffText) {
  const filesChanged = new Set();
  const hunks = [];
  let curPath = null;
  let curHunk = null;
  const flush = () => { if (curHunk && curHunk.lines.length) hunks.push(curHunk); curHunk = null; };
  for (const raw of diffText.split("\n")) {
    if (raw.startsWith("diff --git ")) { flush(); curPath = null; continue; }
    if (raw.startsWith("--- ")) continue;
    if (raw.startsWith("+++ ")) {
      flush();
      const p = raw.slice(4).trim();
      curPath = p === "/dev/null" ? null : p.replace(/^b\//, "");
      if (curPath) filesChanged.add(curPath);
      continue;
    }
    if (raw.startsWith("@@")) { flush(); curHunk = curPath ? { path: curPath, lines: [] } : null; continue; }
    if (!curHunk) continue;
    if (raw.startsWith("+") || raw.startsWith("-") || raw.startsWith(" ")) curHunk.lines.push(raw.slice(1));
  }
  flush();
  return { filesChanged, hunks };
}

// Identifiers >=6 chars; quoted object/lookup keys (`"key":` and `["key"]`,
// >=3 chars); SQL statement openers up to the next `;` (capped at 80 chars so
// one large migration statement cannot dominate the token universe).
const SHAPE_IDENT_RE = /\b[A-Za-z_][A-Za-z0-9_]{5,}\b/g;
const SHAPE_KEY_RE = /["\x27]([A-Za-z_][A-Za-z0-9_.-]{1,63})["\x27]\s*:|\[\s*["\x27]([A-Za-z_][A-Za-z0-9_.-]{1,63})["\x27]\s*\]/g;
const SHAPE_SQL_RE = /\b(?:SELECT|INSERT\s+INTO|UPDATE|DELETE\s+FROM|CREATE\s+(?:UNIQUE\s+)?(?:TABLE|INDEX)|ALTER\s+TABLE)\b[^;]{0,80}/gi;

function extractShapeTokens(text) {
  const idents = new Set();
  const keysAndSql = new Set();
  SHAPE_IDENT_RE.lastIndex = 0;
  for (let m = SHAPE_IDENT_RE.exec(text); m; m = SHAPE_IDENT_RE.exec(text)) idents.add(m[0]);
  SHAPE_KEY_RE.lastIndex = 0;
  for (let m = SHAPE_KEY_RE.exec(text); m; m = SHAPE_KEY_RE.exec(text)) { const k = m[1] ?? m[2]; if (k && k.length >= 3) keysAndSql.add(k); }
  SHAPE_SQL_RE.lastIndex = 0;
  for (let m = SHAPE_SQL_RE.exec(text); m; m = SHAPE_SQL_RE.exec(text)) keysAndSql.add(m[0].replace(/\s+/g, " ").trim().slice(0, 60));
  return { idents, keysAndSql };
}

// Bounded runtime (D-0419 D1: <=60s on this tree). MEASURED, not assumed: a
// `git grep -f <patternfile>` per token class looked cheap on paper and cost
// 20s+ for ~1,270 patterns on a tree this size, and well over two minutes once
// the patterns actually matched (the common ones a `git grep` scan has to walk
// every hit for) -- multi-pattern `-F -f` degrades on match volume, not just
// pattern count, and this tree's own history is full of common words. A single
// pass over every tracked file's text, in this process, scanning for every
// candidate token in one pass per file, measured at ~4s for the same input on
// this tree (6,212 tracked files, ~57MB) -- the cost is proportional to repo
// size once, not to how common a token turns out to be.
const MAX_SHAPE_TOKENS = 4000;
const SHAPE_SCAN_MAX_BYTES = 1_500_000; // skip anything this large; not source code we'd expect a shape in

function scanTreeForTokens(identCandidates, otherCandidates) {
  const identToFiles = new Map();
  const otherToFiles = new Map();
  if (identCandidates.length === 0 && otherCandidates.length === 0) return { identToFiles, otherToFiles };
  const identSet = new Set(identCandidates);
  const IDENT_SCAN_RE = /\b[A-Za-z_][A-Za-z0-9_]{5,}\b/g;
  let files = [];
  try { files = git("ls-files", "-z").split("\0").filter(Boolean); } catch (e) {
    console.error(`harvest-siblings --shape: git ls-files failed: ${String(e.message).split("\n")[0]}`);
    process.exit(2);
  }
  for (const f of files) {
    let st;
    try { st = lstatSync(f); } catch { continue; }
    if (!st.isFile() || st.size > SHAPE_SCAN_MAX_BYTES) continue;
    let txt;
    try { txt = readFileSync(f, "utf8"); } catch { continue; }
    if (identSet.size) {
      IDENT_SCAN_RE.lastIndex = 0;
      let seen = null;
      for (let m = IDENT_SCAN_RE.exec(txt); m; m = IDENT_SCAN_RE.exec(txt)) {
        const t = m[0];
        if (!identSet.has(t)) continue;
        if (!seen) seen = new Set();
        if (seen.has(t)) continue;
        seen.add(t);
        if (!identToFiles.has(t)) identToFiles.set(t, new Set());
        identToFiles.get(t).add(f);
      }
    }
    for (const t of otherCandidates) {
      if (!txt.includes(t)) continue;
      if (!otherToFiles.has(t)) otherToFiles.set(t, new Set());
      otherToFiles.get(t).add(f);
    }
  }
  return { identToFiles, otherToFiles };
}

// ---------------------------------------------------------------- shape scope
// QUEUE #423 (fifth filing: W3-09a FR1/FR3/FR4/RC, then S-094-R5; W3-10-RX and
// S-080 JUDGE H8 had each named it earlier). THE STEP COULD NOT BE DISCHARGED
// AND SAID SO WITH EXIT 0.
//
// Every room contract tells the room to run `--shape=<base>..<candidate>`. A
// room's candidate is an UNCOMMITTED WORKING TREE, and B1 forbids the room the
// commit that would give it a revision name, so there was nothing to put on the
// right of the `..`. Rooms put `HEAD` there. `git diff <base>..HEAD` with the
// base AT HEAD is empty, so the run scanned 0 hunks, wrote a `| _none_ | |`
// table and EXITED 0 -- indistinguishable, to the room and to its reviewer, from
// "I scanned your candidate and it has no siblings". Five rooms spent their time
// rediscovering that. `--strict` did not help: it fires on siblings FOUND (> 0),
// so it is inverted with respect to THIS failure and returned 0 too.
//
// Two things are fixed here and they are separable.
//
// (1) A CANDIDATE THAT NEEDS NO REF. `<base>..WORKTREE` diffs the working tree
// against <base> -- plain `git diff <base>` -- which is what a room's candidate
// actually IS. No ref is minted, no commit is made, the room stays read-only on
// git, and B1 is untouched. This is not a new idea in this file: the
// comment-harvest mode below has ALWAYS used working-tree-vs-HEAD as its default
// subject (`git diff HEAD`, line ~699), untracked files included via
// --include-untracked. SHAPE mode simply could not SAY it -- a single rev goes to
// `git show` (the last COMMIT's diff, i.e. somebody else's work) and an `a..b`
// range goes to `git diff a b`, which never reaches the working tree. Measured
// before this change: `--shape=HEAD..` is accepted and scans 0 hunks, because git
// reads the empty right side as HEAD, not as the tree. So there was NO spelling
// of "my candidate" available to a room, which is the whole of QUEUE #423.
//
// (2) AN EMPTY SCAN IS NOW LOUD, FOR EVERY SPEC, NOT JUST THE NEW ONE. Zero
// hunks is not a result; it is the ABSENCE of one. It now prints
// `SCANNED: 0 files -- <reason>` and exits SHAPE_EMPTY_EXIT (2 is already
// usage/git failure, 1 is already --strict). A check whose input can be EMPTY
// passes trivially, and this one did. The reason string names the cause,
// including the specific one five rooms hit: both sides of the range resolving to
// the same commit. The failing run still OVERWRITES the report, with a body that
// says NOT DISCHARGED: leaving the previous run's file in place would let the
// next room read a stale SIBLINGS table as its own result, which is the same
// defect wearing a different hat.
const SHAPE_EMPTY_EXIT = 3;
const WORKTREE_SUFFIX = "..WORKTREE";

// The spec -> the git argv that produces its diff. `worktreeBase` is non-null
// exactly when the diff ENDS AT THE WORKING TREE, which is what gates
// --include-untracked below.
function shapeDiffPlan(spec) {
  const ps = PATHSPEC.length ? ["--", ...PATHSPEC] : [];
  const up = spec.toUpperCase();
  if (up === "WORKTREE" || up.endsWith(WORKTREE_SUFFIX)) {
    const base = up === "WORKTREE" ? "HEAD" : spec.slice(0, spec.length - WORKTREE_SUFFIX.length) || "HEAD";
    return { argv: ["diff", "--no-color", "--no-ext-diff", "--no-renames", base, ...ps], worktreeBase: base };
  }
  if (spec.includes("..")) {
    return { argv: ["diff", "--no-color", "--no-ext-diff", "--no-renames", spec, ...ps], worktreeBase: null };
  }
  return { argv: ["show", "--no-color", "--no-ext-diff", "--no-renames", "--format=", spec, ...ps], worktreeBase: null };
}

function shapeRevOf(r) {
  try { return git("rev-parse", "--verify", "--quiet", `${r}^{commit}`).trim() || null; } catch { return null; }
}

// Why nothing was scanned, in the words the room needs to act on. This string is
// the whole remedy for the repeat filings: it must name the fix, not the symptom.
function shapeEmptyReason(spec, plan) {
  const bits = [];
  if (plan.worktreeBase) {
    bits.push(`the working tree is byte-identical to ${plan.worktreeBase}, so there is no candidate to scan`);
    if (!UNTRACKED) bits.push("`git diff` cannot see UNTRACKED files -- if your candidate is new files, re-run with --include-untracked");
  } else if (spec.includes("..")) {
    const [a, b] = spec.split("..");
    const ra = shapeRevOf(a || "HEAD");
    const rb = shapeRevOf(b || "HEAD");
    if (ra && rb && ra === rb) {
      bits.push(`both sides of \`${spec}\` resolve to the SAME commit ${ra.slice(0, 7)}`);
      bits.push(`an uncommitted candidate has no revision name, so it cannot be named here -- use \`${a || "HEAD"}..WORKTREE\` to scan the working tree itself (QUEUE #423)`);
    } else {
      bits.push(`\`git diff ${spec}\` produced no hunks`);
    }
  } else {
    bits.push(`\`git show ${spec}\` produced no hunks (a single rev scans that COMMIT, not your working tree -- use \`${spec}..WORKTREE\` for the tree)`);
  }
  if (PATHSPEC.length) bits.push(`the pathspec \`${PATHSPEC.join(" ")}\` may have excluded everything`);
  return bits.join("; ");
}

function runShapeMode(spec) {
  const plan = shapeDiffPlan(spec);
  // QUEUE #477 (B23-D9): a single rev (or an a..b range) scans COMMITTED work — most often the
  // orchestrator's last commit — and exits 0 with a full, confident table. Said on stderr, where a
  // room reads it, not only in the report header.
  if (!plan.worktreeBase) console.error(`candidate: a committed revision (NOT your working tree) -- \`--shape=${spec}\` scans ${spec.includes("..") ? "that commit range" : "that one commit"}; use \`--shape=<base>..WORKTREE\` to scan your uncommitted candidate`);
  // B23-D9 (QUEUE #477 second limb): in a SHARED build tree the working tree carries every live
  // room's candidate, so an unscoped WORKTREE scan is every room's diff. Scope it with a pathspec.
  if (plan.worktreeBase && !PATHSPEC.length) console.error(`SHARED-TREE: \`--shape=${spec}\` with no pathspec scans EVERY uncommitted change in this tree -- in a shared build tree that is every live room's candidate, not yours. Append \`-- <your OWNS paths>\` to scope it.`);
  if (UNTRACKED && !plan.worktreeBase) {
    console.error("harvest-siblings --shape: --include-untracked needs the working tree as the diff end -- use `--shape=<base>..WORKTREE`");
    process.exit(2);
  }
  let diffText;
  try {
    diffText = git(...plan.argv);
  } catch (e) {
    console.error(`harvest-siblings --shape: cannot read diff for ${spec}: ${String(e.message).split("\n")[0]}`);
    process.exit(2);
  }
  if (UNTRACKED) {
    // A synthetic all-added hunk per untracked file, fed through the same parser
    // as the real diff -- the identical idiom the comment-harvest mode uses
    // (S-074 J74-03). Read-only: no `git add -N`.
    let untrackedList = [];
    // B23-D9: the pathspec scopes the untracked listing too. Without it `-- <paths>` narrowed the diff
    // and still folded every untracked file in the tree — every sibling room's new files — back in.
    try { untrackedList = git("ls-files", "--others", "--exclude-standard", "-z", ...(PATHSPEC.length ? ["--", ...PATHSPEC] : [])).split("\0").filter(Boolean); } catch (e) {
      console.error(`harvest-siblings --shape: git ls-files --others failed: ${String(e.message).split("\n")[0]}`);
      process.exit(2);
    }
    for (const f of untrackedList) {
      if (!langOf(f)) continue;
      let st;
      try { st = lstatSync(f); } catch { continue; }
      if (!st.isFile() || st.size > SHAPE_SCAN_MAX_BYTES) continue;
      let body;
      try { body = readFileSync(f, "utf8").replace(/\n$/, "").split("\n"); } catch { continue; }
      diffText += `\ndiff --git a/${f} b/${f}\n--- /dev/null\n+++ b/${f}\n@@ -0,0 +1,${body.length} @@\n${body.map((l) => `+${l}`).join("\n")}\n`;
    }
  }
  const { filesChanged, hunks } = parseHunksForShape(diffText);

  // THE EMPTY-INPUT GATE (QUEUE #423). Nothing scanned => nothing proved.
  if (hunks.length === 0) {
    const reason = shapeEmptyReason(spec, plan);
    const scope = `--shape=${spec}${UNTRACKED ? " --include-untracked" : ""}${PATHSPEC.length ? ` -- ${PATHSPEC.join(" ")}` : ""}`;
    const F = [];
    F.push(`# Sibling harvest -- SHAPE mode -- NOT DISCHARGED`);
    F.push("");
    F.push(`SCANNED: 0 files -- ${reason}`);
    F.push("");
    F.push(`- scope: \`${scope}\``);
    F.push(`- generated: ${new Date().toISOString()}`);
    F.push(`- exit: ${SHAPE_EMPTY_EXIT}`);
    F.push("");
    F.push(`This run produced NO result and discharges NOTHING. There is no SIBLINGS table`);
    F.push(`below because no hunk was read; an empty table here would be a claim that the`);
    F.push(`candidate was examined and found clean, and it was not examined at all.`);
    F.push("");
    if (dirname(OUT) && !existsSync(dirname(OUT))) mkdirSync(dirname(OUT), { recursive: true });
    writeFileSync(OUT, `${F.join("\n")}\n`);
    console.error(`harvest-siblings --shape: ${spec}`);
    console.error(`SCANNED: 0 files -- ${reason}`);
    console.error(`harvest-siblings --shape: NOTHING WAS SCANNED; this step is NOT discharged (exit ${SHAPE_EMPTY_EXIT}). Report: ${OUT}`);
    process.exit(SHAPE_EMPTY_EXIT);
  }

  const identUniverse = new Set();
  const otherUniverse = new Set();
  const perHunk = [];
  for (const h of hunks) {
    const { idents, keysAndSql } = extractShapeTokens(h.lines.join(" "));
    for (const t of idents) identUniverse.add(t);
    for (const t of keysAndSql) otherUniverse.add(t);
    perHunk.push({ path: h.path, idents, keysAndSql });
  }
  let identList = [...identUniverse];
  let otherList = [...otherUniverse];
  let truncated = false;
  if (identList.length + otherList.length > MAX_SHAPE_TOKENS) {
    truncated = true;
    identList = identList.slice(0, Math.floor(MAX_SHAPE_TOKENS / 2));
    otherList = otherList.slice(0, Math.floor(MAX_SHAPE_TOKENS / 2));
  }
  const { identToFiles: identFiles, otherToFiles: otherFiles } = scanTreeForTokens(identList, otherList);
  const rareIdent = new Set([...identFiles.keys()].filter((t) => identFiles.get(t).size <= 20));
  const rareOther = new Set([...otherFiles.keys()].filter((t) => otherFiles.get(t).size <= 20));

  const sharedBy = new Map();
  for (const h of perHunk) {
    for (const t of h.idents) {
      if (!rareIdent.has(t)) continue;
      for (const f of identFiles.get(t)) {
        if (filesChanged.has(f) || f === h.path) continue;
        if (!sharedBy.has(f)) sharedBy.set(f, new Set());
        sharedBy.get(f).add(t);
      }
    }
    for (const t of h.keysAndSql) {
      if (!rareOther.has(t)) continue;
      for (const f of otherFiles.get(t)) {
        if (filesChanged.has(f) || f === h.path) continue;
        if (!sharedBy.has(f)) sharedBy.set(f, new Set());
        sharedBy.get(f).add(t);
      }
    }
  }
  const shapeRowsAll = [...sharedBy.entries()]
    .map(([path, toks]) => ({ path, tokens: [...toks].sort(), count: toks.size }))
    .filter((r) => r.count >= 2)
    .sort((a, b) => b.count - a.count || a.path.localeCompare(b.path));
  const shapeRowsTotal = shapeRowsAll.length;
  const shapeCapped = !SHAPE_ALL && shapeRowsTotal > SHAPE_CAP;
  const shapeRows = shapeCapped ? shapeRowsAll.slice(0, SHAPE_CAP) : shapeRowsAll;

  const L = [];
  L.push(`# Sibling harvest -- SHAPE mode (ANTI-021 second clause, D-0419)`);
  L.push("");
  L.push(`- scope: \`--shape=${spec}${UNTRACKED ? " --include-untracked" : ""}${PATHSPEC.length ? ` -- ${PATHSPEC.join(" ")}` : ""}\``);
  L.push(`- candidate: ${plan.worktreeBase ? `the WORKING TREE against ${plan.worktreeBase} (no ref, no commit)` : "a committed revision (NOT your working tree)"}`);
  if (plan.worktreeBase && !PATHSPEC.length) L.push(`- SHARED-TREE: no pathspec, so this scanned every uncommitted change in the tree -- in a shared build tree, every live room's candidate`);
  L.push(`- generated: ${new Date().toISOString()}`);
  L.push(`- SCANNED: ${filesChanged.size} file(s), ${hunks.length} hunk(s)`);
  L.push(`- hunks scanned: ${hunks.length}, changed files excluded: ${filesChanged.size}`);
  L.push(`- distinctive tokens (<=20 tracked files): ${rareIdent.size} identifier(s), ${rareOther.size} key/SQL fragment(s)${truncated ? " -- TOKEN UNIVERSE TRUNCATED at " + MAX_SHAPE_TOKENS : ""}`);
  L.push(`- siblings: ${shapeRowsTotal} file(s) with >=2 shared tokens, ranked by shared-token count${shapeCapped ? ` -- showing the top ${SHAPE_CAP} (--all for the full ${shapeRowsTotal})` : ""}`);
  L.push("");
  L.push(`## SIBLINGS`);
  L.push("");
  L.push(`| path | shared tokens | count |`);
  L.push(`|---|---|---|`);
  if (shapeRows.length === 0) L.push(`| _none_ | | |`);
  for (const r of shapeRows) L.push(`| \`${r.path}\` | ${r.tokens.map((t) => `\`${t}\``).join(", ")} | ${r.count} |`);
  L.push("");
  if (dirname(OUT) && !existsSync(dirname(OUT))) mkdirSync(dirname(OUT), { recursive: true });
  writeFileSync(OUT, `${L.join("\n")}\n`);
  console.log(`harvest-siblings --shape: ${spec}`);
  console.log(`  SCANNED: ${filesChanged.size} file(s), ${hunks.length} hunk(s)`);
  console.log(`  hunks     ${hunks.length} scanned across ${filesChanged.size} changed file(s)`);
  console.log(`  tokens    ${rareIdent.size} rare identifier(s), ${rareOther.size} rare key/SQL fragment(s)${truncated ? " (TRUNCATED)" : ""}`);
  console.log(`  siblings  ${shapeRowsTotal} file(s) with >=2 shared tokens${shapeCapped ? ` (showing top ${SHAPE_CAP}; --all for the full list)` : ""}`);
  for (const r of shapeRows) console.log(`    ${String(r.count).padStart(3)}  ${r.path}  [${r.tokens.slice(0, 6).join(", ")}${r.tokens.length > 6 ? ", ..." : ""}]`);
  console.log(`  report    ${OUT}`);
  console.error(`harvest-siblings: wrote ${resolvePath(OUT)}`);
  if (STRICT && shapeRowsTotal > 0) {
    console.error(`harvest-siblings --shape: --strict and ${shapeRowsTotal} sibling(s) found.`);
    process.exit(1);
  }
  process.exit(0);
}

// ----------------------------------------------------------------- diff pass
function parseDiff(text) {
  const changed = new Set();
  const added = new Map();
  let cur = null;
  let newLine = 0;
  for (const raw of text.split("\n")) {
    if (raw.startsWith("diff --git ")) { cur = null; continue; }
    if (raw.startsWith("--- ")) { const p = raw.slice(4).trim(); if (p !== "/dev/null") changed.add(p.replace(/^a\//, "")); continue; }
    if (raw.startsWith("+++ ")) {
      const p = raw.slice(4).trim();
      if (p === "/dev/null") { cur = null; } else { cur = p.replace(/^b\//, ""); changed.add(cur); }
      continue;
    }
    if (raw.startsWith("@@")) { const m = /^@@ -\d+(?:,\d+)? \+(\d+)(?:,(\d+))? @@/.exec(raw); if (m) newLine = Number(m[1]); continue; }
    if (!cur) continue;
    if (raw.startsWith("+")) { if (!added.has(cur)) added.set(cur, []); added.get(cur).push({ n: newLine, text: raw.slice(1) }); newLine++; continue; }
    if (raw.startsWith("-")) continue;
    if (raw.startsWith(" ")) { newLine++; continue; }
  }
  return { changed, added };
}

const contentCache = new Map();
function linesAt(rev, path) {
  const key = `${rev ?? "@wt"}:${path}`;
  if (contentCache.has(key)) return contentCache.get(key);
  let txt = null;
  // QUEUE #230: null means "not in that revision / not on disk" and nothing else.
  if (rev) {
    try { txt = execFileSync("git", ["show", `${rev}:${path}`], { encoding: "utf8", maxBuffer: 1024 * 1024 * 1024, stdio: ["ignore", "pipe", "pipe"] }); } catch (e) {
      const err = String(e.stderr ?? "");
      if (!isPathNotInRef(err)) { console.error(`harvest-siblings: git show ${rev}:${path} cannot be read: ${err.trim() || e.message}`); process.exit(2); }
    }
  } else {
    try { txt = readFileSync(path, "utf8"); } catch (e) {
      if (e.code !== "ENOENT") { console.error(`harvest-siblings: ${path} cannot be read: ${e.message}`); process.exit(2); }
    }
  }
  const v = txt === null ? null : txt.split("\n");
  contentCache.set(key, v);
  return v;
}

const stats = { files: 0, addedLines: 0, commentAdded: 0, refs: 0, unresolved: 0, self: 0, coChanged: 0 };
const hits = [];

function scanDiff(diffText, endRev, label) {
  const { changed, added } = parseDiff(diffText);
  for (const [path, lines] of added) {
    stats.addedLines += lines.length;
    const lang = langOf(path);
    if (!lang) continue;
    // Pre-filter: only files whose added text even mentions a candidate path are
    // worth materialising at this revision. On a 76-commit sweep this is the
    // difference between a few dozen `git show`s and several thousand.
    EXT_G.lastIndex = 0;
    if (!lines.some((l) => { EXT_G.lastIndex = 0; return EXT_G.test(l.text); })) continue;
    const src = linesAt(endRev, path);
    if (!src) continue;
    stats.files++;
    const cmt = commentsOf(src, lang);
    for (const { n } of lines) {
      const i = n - 1;
      if (i < 0 || i >= cmt.length) continue;
      if (!cmt[i]) continue;
      stats.commentAdded++;
      // The enclosing comment block: the room's deferral sentence and its
      // filename land on different lines far more often than not.
      let a = i; while (a > 0 && cmt[a - 1]) a--;
      let b = i; while (b + 1 < cmt.length && cmt[b + 1]) b++;
      const block = cmt.slice(a, b + 1).join(" ").replace(/\s+/g, " ").trim();
      const { s, hit } = score(block);
      EXT_G.lastIndex = 0;
      const seen = new Set();
      // Assignment hoisted out of the loop condition: biome's noAssignInExpressions
      // is an error here, not a warning, and `pnpm lint` is a blocking gate leg.
      let m = EXT_G.exec(cmt[i]);
      for (; m !== null; m = EXT_G.exec(cmt[i])) {
        const raw = m[1];
        if (seen.has(raw)) continue;
        seen.add(raw);
        stats.refs++;
        const target = resolve(raw);
        if (!target) { stats.unresolved++; continue; }
        if (target === path) { stats.self++; continue; }
        if (isTest(target) !== isTest(path) && stemOf(target) === stemOf(path)) { stats.self++; continue; }
        if (changed.has(target)) { stats.coChanged++; continue; }
        hits.push({ path, line: n, raw, target, score: s, signals: hit, block, commit: label });
      }
    }
  }
}

#!/usr/bin/env node
/**
 * I3-0705 (D-1078(7)) — one-off: FACE_INDEX vectors written before I3-0705 carry the creator's `passport_id` as
 * Vectorize METADATA (services/image/src/env.ts VectorizeStore now upserts `{ id, values }` only). This script finds
 * them by id and either re-upserts each WITHOUT metadata (`strip`) or deletes it (`wipe`). Face enrolment stays off
 * (FACE_ENROLLMENT_ENABLED "false"); DEPLOY.md's FACE_ENROLLMENT_ENABLED row and its I3-0705 runbook entry say when to
 * run it.
 *
 *   CLOUDFLARE_ACCOUNT_ID=… CLOUDFLARE_API_TOKEN=… node scripts/i32-face-index-metadata.mjs \
 *     --index dhwaja-faces-<env> --ids <file> [--mode check|strip|wipe]
 *
 * `--ids` is one vector id per line, or the `--json` output of
 * `wrangler d1 execute IMAGE_DB --remote --json --command "SELECT image_id FROM enrollments"` (every object's
 * `image_id`). `check` (the default) changes nothing and exits 1 while any listed vector still carries metadata.
 * Metadata VALUES are never printed — they are the identifiers this exists to remove. Vectorize applies a mutation
 * asynchronously, so `strip`/`wipe` print the mutation ids and are confirmed by a later `check`.
 */
import { readFileSync, realpathSync } from "node:fs";
import { resolve } from "node:path";
import { fileURLToPath } from "node:url";

export const CHUNK = 20; // Vectorize get_by_ids / delete_by_ids batch (services/image/src/env.ts RECONCILE_INVENTORY_CHUNK)
const API = "https://api.cloudflare.com/client/v4/accounts";

/** Vector ids from a newline list or wrangler's d1 `--json` output; de-duplicated, order kept. */
export function parseIds(text) {
  const t = text.trim();
  let ids;
  if (t.startsWith("[") || t.startsWith("{")) {
    const doc = JSON.parse(t);
    const blocks = Array.isArray(doc) ? doc : [doc];
    ids = blocks.flatMap((b) => (Array.isArray(b?.results) ? b.results : [b])).map((r) => r?.image_id);
  } else ids = t.split(/\r?\n/).map((l) => l.trim());
  const bad = ids.filter((i) => typeof i !== "string" || !/^[A-Za-z0-9_-]{1,64}$/.test(i));
  if (bad.length > 0) throw new Error(`${bad.length} id(s) are not vector ids (1-64 of [A-Za-z0-9_-]); nothing was sent`);
  return [...new Set(ids)];
}

const hasMetadata = (v) => v.metadata !== undefined && v.metadata !== null && Object.keys(v.metadata).length > 0;

function client({ account, token, index, fetchImpl }) {
  const base = `${API}/${encodeURIComponent(account)}/vectorize/v2/indexes/${encodeURIComponent(index)}`;
  async function call(path, body, contentType = "application/json") {
    const res = await fetchImpl(`${base}/${path}`, { method: "POST", headers: { Authorization: `Bearer ${token}`, "Content-Type": contentType }, body });
    const j = await res.json().catch(() => null);
    if (!res.ok || j?.success !== true) throw new Error(`${path}: HTTP ${res.status}${j?.errors?.[0]?.message ? ` — ${j.errors[0].message}` : ""}`);
    return j.result;
  }
  return {
    getByIds: (ids) => call("get_by_ids", JSON.stringify({ ids })),
    upsert: (vectors) => call("upsert", vectors.map((v) => JSON.stringify(v)).join("\n"), "application/x-ndjson"),
    deleteByIds: (ids) => call("delete_by_ids", JSON.stringify({ ids })),
  };
}

/** Run one mode over `ids`. Returns the counts and mutation ids; never the metadata. */
export async function run({ mode, ids, account, token, index, fetchImpl = fetch }) {
  if (!["check", "strip", "wipe"].includes(mode)) throw new Error(`--mode must be check, strip or wipe (got ${mode})`);
  if (!account || !token) throw new Error("CLOUDFLARE_ACCOUNT_ID and CLOUDFLARE_API_TOKEN are required");
  if (!/^dhwaja-faces-[a-z]+$/.test(index ?? "")) throw new Error("--index must name a FACE_INDEX (dhwaja-faces-<env>)");
  const api = client({ account, token, index, fetchImpl });
  const out = { listed: ids.length, found: 0, with_metadata: 0, mutations: [] };
  for (let i = 0; i < ids.length; i += CHUNK) {
    const chunk = ids.slice(i, i + CHUNK);
    const found = (await api.getByIds(chunk)) ?? [];
    out.found += found.length;
    const labelled = found.filter(hasMetadata);
    out.with_metadata += labelled.length;
    if (mode === "strip" && labelled.length > 0) out.mutations.push((await api.upsert(labelled.map((v) => ({ id: v.id, values: v.values }))))?.mutationId ?? null);
    if (mode === "wipe" && found.length > 0) out.mutations.push((await api.deleteByIds(found.map((v) => v.id)))?.mutationId ?? null);
  }
  return out;
}

function parseArgs(argv) {
  const o = { mode: "check" };
  for (let i = 0; i < argv.length; i++) {
    const k = argv[i];
    if (k === "--index") o.index = argv[++i];
    else if (k === "--ids") o.idsFile = argv[++i];
    else if (k === "--mode") o.mode = argv[++i];
    else throw new Error(`unknown argument ${k}`);
  }
  if (!o.idsFile) throw new Error("--ids <file> is required");
  return o;
}

export async function main(argv, { env = process.env, fetchImpl = fetch, log = (s) => process.stdout.write(s), err = (s) => process.stderr.write(s) } = {}) {
  try {
    const o = parseArgs(argv);
    const ids = parseIds(readFileSync(o.idsFile, "utf8"));
    const r = await run({ mode: o.mode, ids, account: env.CLOUDFLARE_ACCOUNT_ID, token: env.CLOUDFLARE_API_TOKEN, index: o.index, fetchImpl });
    log(`${o.mode} ${o.index}: listed ${r.listed}, found ${r.found}, carrying metadata ${r.with_metadata}${r.mutations.length ? `, mutations ${r.mutations.join(" ")}` : ""}\n`);
    if (o.mode === "check") return r.with_metadata > 0 ? 1 : 0;
    log("Vectorize applies mutations asynchronously: run --mode check again in a minute; it exits 0 once no listed vector carries metadata.\n");
    return 0;
  } catch (e) {
    err(`i32-face-index-metadata: ${e instanceof Error ? e.message : String(e)}\n`);
    return 2;
  }
}

const realOr = (p) => {
  try {
    return realpathSync(p);
  } catch {
    return resolve(p);
  }
};
if (process.argv[1] && realOr(process.argv[1]) === realOr(fileURLToPath(import.meta.url))) process.exitCode = await main(process.argv.slice(2));

 * Two ECDSA P-256 key pairs (REGISTRY_SIG_ALG "ECDSA-P256-SHA256", packages/registry-proof/src/registry-proof.ts). The
 * PRIVATE halves are written as PKCS#8 PEM files, mode 0600, never overwriting, into `--out`, which must be OUTSIDE this
 * repository: the script refuses a directory inside it (or inside the git work tree it is run from). The PUBLIC halves

 * packages/registry-proof/src/registry-keys.ts, the `REGISTRY_PUBLIC_KEYS` JSON for services/trust-core/wrangler.jsonc,

import { execFileSync } from "node:child_process";
import { existsSync, mkdirSync, realpathSync, writeFileSync } from "node:fs";
import { dirname, join, relative, resolve, isAbsolute } from "node:path";
import { fileURLToPath } from "node:url";

export const REGISTRY_SIG_ALG = "ECDSA-P256-SHA256";
export const KEY_ID_RE = /^[a-z0-9][a-z0-9._-]{0,63}$/; // packages/registry-proof/src/registry-proof.ts KEY_ID_RE
const REPO_ROOT = resolve(dirname(fileURLToPath(import.meta.url)), "..");

const realOr = (p) => {
  try {
    return realpathSync(p);
  } catch {
    return resolve(p);
  }
};
/** The nearest existing ancestor, resolved through symlinks, so a not-yet-created `--out` is judged where it would land. */
function landing(p) {
  let cur = resolve(p);
  const tail = [];
  while (!existsSync(cur)) {
    tail.unshift(cur.slice(dirname(cur).length + 1));
    const up = dirname(cur);
    if (up === cur) break;
    cur = up;
  }
  return join(realOr(cur), ...tail);
}
const inside = (child, parent) => {
  const r = relative(parent, child);
  return r === "" || (!r.startsWith("..") && !isAbsolute(r));
};
function gitTop(cwd) {
  try {
    return execFileSync("git", ["-C", cwd, "rev-parse", "--show-toplevel"], { encoding: "utf8", stdio: ["ignore", "pipe", "ignore"] }).trim();
  } catch {
    return null;
  }
}

/** Why `out` may not hold a private key, or null. */
export function refuseOut(out, { repoRoot = REPO_ROOT, cwd = process.cwd() } = {}) {
  if (typeof out !== "string" || out.trim() === "") return "--out <dir> is required: the private keys must be written somewhere you choose, outside this repository";
  const where = landing(out);
  for (const root of [repoRoot, gitTop(cwd)].filter(Boolean)) {
    if (inside(where, realOr(root))) return `--out ${out} is inside the repository (${realOr(root)}); a private key is never written into the repo`;
  }
  return null;
}

const b64 = (bytes) => Buffer.from(bytes).toString("base64");
const pem = (der) => `-----BEGIN PRIVATE KEY-----\n${b64(der).replace(/(.{64})/g, "$1\n").replace(/\n$/, "")}\n-----END PRIVATE KEY-----\n`;

/** One P-256 pair, proven usable: it signs, and the printed SPKI verifies that signature. */
async function pair(subtle) {
  const kp = await subtle.generateKey({ name: "ECDSA", namedCurve: "P-256" }, true, ["sign", "verify"]);
  const spki = new Uint8Array(await subtle.exportKey("spki", kp.publicKey));
  const pkcs8 = new Uint8Array(await subtle.exportKey("pkcs8", kp.privateKey));
  const probe = new TextEncoder().encode("i32-registry-keygen self-check");
  const sig = await subtle.sign({ name: "ECDSA", hash: "SHA-256" }, kp.privateKey, probe);
  const pub = await subtle.importKey("spki", spki, { name: "ECDSA", namedCurve: "P-256" }, false, ["verify"]);
  if (!(await subtle.verify({ name: "ECDSA", hash: "SHA-256" }, pub, sig, probe))) throw new Error("self-check failed: the generated key does not verify its own signature");
  return { spki: b64(spki), pkcs8 };
}

/** Generate both pairs, write the private halves into `out`, return the public rows. Throws on any refusal. */
export async function generate({ out, id, now = new Date(), subtle = globalThis.crypto.subtle, repoRoot = REPO_ROOT, cwd = process.cwd() }) {
  const refused = refuseOut(out, { repoRoot, cwd });
  if (refused) throw new Error(refused);
  const primaryId = id ?? `rk-${now.toISOString().slice(0, 7)}`;
  const backupId = `${primaryId}-backup`;
  for (const k of [primaryId, backupId]) if (!KEY_ID_RE.test(k)) throw new Error(`key id ${JSON.stringify(k)} does not match KEY_ID_RE ${KEY_ID_RE}`);
  const files = { primary: join(out, `${primaryId}.pkcs8.pem`), backup: join(out, `${backupId}.pkcs8.pem`) };
  for (const f of Object.values(files)) if (existsSync(f)) throw new Error(`${f} already exists; refusing to overwrite a private key`);
  const [p, b] = [await pair(subtle), await pair(subtle)];
  mkdirSync(out, { recursive: true, mode: 0o700 });
  writeFileSync(files.primary, pem(p.pkcs8), { mode: 0o600, flag: "wx" });
  writeFileSync(files.backup, pem(b.pkcs8), { mode: 0o600, flag: "wx" });
  // No `not_before`: omitted means no lower bound (registry-keys.ts PublishedKey), so a build dated before this
  // machine's clock is not refused; `generated` is for the DEPLOY.md table only.
  const keys = [
    { key_id: primaryId, alg: REGISTRY_SIG_ALG, pub: p.spki },
    { key_id: backupId, alg: REGISTRY_SIG_ALG, pub: b.spki },
  ];
  return { files, keys, generated: now.toISOString().slice(0, 10) };
}

export function render({ files, keys, generated }) {
  const ts = keys.map((k) => `  { key_id: ${JSON.stringify(k.key_id)}, alg: ${JSON.stringify(k.alg)}, pub: ${JSON.stringify(k.pub)} },`);
  const wrangler = JSON.stringify(keys);
  const table = keys.map((k, i) => `| ${k.key_id} | ${generated}${i === 1 ? " (backup, pre-announced; not signing)" : ""} | ${k.pub} |`);
  return [
    "PRIVATE KEYS written (mode 0600) — move the backup offline now; neither file belongs in this repository:",
    `  primary: ${files.primary}`,
    `  backup:  ${files.backup}`,
    "",

    ...ts,
    "",
    "2. services/trust-core/wrangler.jsonc — REGISTRY_PUBLIC_KEYS (every environment block that signs):",
    `  ${wrangler}`,
    "",
    "3. DEPLOY.md §3a-bis — Published registry keys:",
    ...table,
    "",
    "4. Android — the `dhwaja.publishedRegistryKeys` value (apps/android/app/build.gradle.kts -> BuildConfig.PUBLISHED_REGISTRY_KEYS):",
    `  ${JSON.stringify(keys.map((k) => [k.key_id, k.pub]))}`,
    "",
    "5. iOS — Info.plist `DhwajaPublishedRegistryKeys` (apps/ios/App/AppConfig.swift):",
    "  <array>",
    ...keys.map((k) => `    <dict><key>kid</key><string>${k.key_id}</string><key>spki</key><string>${k.pub}</string></dict>`),
    "  </array>",
    "",
  ].join("\n");
}

    else throw new Error(`unknown argument ${argv[i]}`);
  }

/**
 * Attribute ONE parsed row. Never guesses: a single prose id with a mention cue before it, and
 * any row with more than one candidate, is unattributable with the candidates recorded.
 * @param {Record<string, unknown>} row
 */
export function attribute(row) {
  if (!row || typeof row !== "object" || Array.isArray(row)) return { attribution: "unattributable", reason: "not-an-object" };
  if (row[REGISTER_KEY] !== undefined && row[REGISTER_KEY] !== null) {
    if (isIidNone(row[REGISTER_KEY])) return { attribution: "unattributable", reason: "declared-none" };
    const ids = normalizeRegisterIds(row[REGISTER_KEY]);
    if (ids.length) return { attribution: "attributed", method: "declared", iid: ids };
    return { attribution: "unattributable", reason: "declared-unparseable", declared: row[REGISTER_KEY] };
  }
  for (const k of REGISTER_ALIAS_KEYS) {
    if (row[k] === undefined || row[k] === null) continue;
    const ids = normalizeRegisterIds(row[k]);
    if (ids.length) return { attribution: "attributed", method: "alias", alias: k, iid: ids };
  }
  const ownId = String(row.id ?? "").trim();
  if (isRegisterId(ownId)) return { attribution: "attributed", method: "own-id", iid: [ownId.toUpperCase()] };
  // Each field is judged on its own, as the ledger's per-field scan judges it (a U+0000 join let a cue
  // or a negation in `mechanism` reach the `id` field and the two indexes disagreed).
  const fields = [row.id, row.mechanism, row.file].filter((x) => typeof x === "string");
  const found = [...new Set(fields.flatMap((f) => [...f.matchAll(REGISTER_ID_RE)].map((m) => m[0].toUpperCase())))];
  if (found.length === 0) return { attribution: "unattributable", reason: "no-id" };
  // More than one candidate is refused BEFORE negation (base order): a row that negates one of two
  // ids does not thereby assert the other ('NOT the same defect as I3-0963, I3-0964').
  if (found.length > 1) return { attribution: "unattributable", reason: "prose-multi", candidates: found };
  const id = found[0];
  const f = fields.find((x) => x.includes(id));
  const at = f.indexOf(id);
  // Negation is read `exclusionsOnly`: an exclusion that GOVERNS the id ('without I3-0963', 'independent
  // of I3-0963') or a negated list it is an item of ('NOT the same defect as I3-0001, I3-0963') refuses
  // it; a negated PREDICATE ('I3-1411 premise does not reproduce' -- the disposition itself) is left to
  // base's cue window below, which refused 'NOT the same defect as I3-0963' and 'I3-0963 is not' already.
  // A clause-opening `no` quantifies over the evidence, not the item ('No test reddens on the I3-0032
  // mutations', a `defended` row); base never read it as a cue, so it is neutralised here.
  const text = f.replace(/(?<![\w#)\]'"`\u2019]\s+)(?<![\w-])no(?=\s+(?!longer(?![\w-]))[\w#])/gi, "any");
  if (!assertedClauses(text, { exclusionsOnly: true }).some((c) => c.includes(id))) return { attribution: "unattributable", reason: "prose-mention", candidates: found };

}

/** Every <batch>/<room>/FINDINGS.jsonl under root, following symlinked dirs (statSync), sorted. */
export function listFindings(findingsRoot) {
  const out = [];
  if (!existsSync(findingsRoot)) return out;
  const isDir = (p) => { try { return statSync(p).isDirectory(); } catch { return false; } };
  for (const batch of readdirSync(findingsRoot).sort()) {
    const bdir = join(findingsRoot, batch);
    if (!isDir(bdir)) continue;
    for (const room of readdirSync(bdir).sort()) {
      const p = join(bdir, room, "FINDINGS.jsonl");
      if (isDir(join(bdir, room)) && existsSync(p)) out.push({ batch, room, path: p });
    }
  }
  return out;
}

/** Build the sidecar rows and the counts. Pure over the files it reads. */

          counts.status_unmappable++;

      else counts.unattributable[out.reason] = (counts.unattributable[out.reason] ?? 0) + 1;
      rows.push(out);
    });
  }
  return { rows, counts };
}

/**
 * intake-id-diff.mjs — QUEUE #144 (F-34, "a finding that never became a row"). READ-ONLY.
 *
 * JUDGE-0003 found F-34 bleeding out of a corrupted extractor block: real at HEAD, never parsed
 * into the register as its own entry. This script asks the question the extractor cannot ask of
 * itself: which finding ids sit at a BLOCK START in a source document but are in no register?
 *
 * The block-start scan below is deliberately NOT intake-parse.mjs's adapter regexes — a scanner
 * that shares the extractor's header shapes shares its blind spots. It accepts a heading, a
 * bold line, a table row or a list bold, with one id or a `A / B` list, and reads each id.
 *
 * Classes for a source id:
 *   REGISTERED  a `| id |` row under the matching `## Source XX` section of the register.
 *   RECORDED    (I8-FX3 T2-13) a JSON RECORD in the accounted files — an object with its own `source` code
 *               equal to THIS source's and a `verdict` that is not a `not_duplicate`-style one — filed under
 *               this id (its key or its `id`). Keyed by (source code, id): another source's C1 is not this
 *               source's C1, a bare id-shaped key in a non-record is nothing, and a record with no source or
 *               no verdict is not attributable (ANTI-023: a pointer never retires a row on its own text).
 *   MENTIONED   the id appears in a markdown/prose file of the accounted set (a block start there has no source
 *               code, so it cannot be RECORDED). Listed, never counted as safe.
 *   PARKED      the head itself says `— REJECTED` / `— NEEDS_REPRO` and the register has no row (the
 *               extractor parks those by design; NEEDS_REPRO is still a lead, so it is listed).
 *   MISSING     none of the above.
 * Exit codes, one meaning each (highest-priority first):
 *   4  an uncaught throw (unreadable file, EISDIR, ...): the run did not complete.
 *   2  no population: the register, the sources or ALL block-start ids are empty, OR (I8-FX3 T2-12) ANY single
 *      source has zero block-start ids and no id-less severity heads (`### [MEDIUM] title`, persona-swarm's
 *      shape) — a truncated or drifted source is not a clean one. Nothing to compare is not green.
 *   1  a MISSING or MENTIONED id.
 *   3  (I8-FX3 T2-14) nothing missing, but a PARKED `— NEEDS_REPRO` row remains: still a lead, never a plain OK.
 *   0  everything accounted for (PARKED `— REJECTED` rows are parked by design).
 *
 *   node scripts/intake-id-diff.mjs [--root <dir>] [--sources a,b] [--register <md>]
 *        [--accounted a,b] [--out <md>] [--json] [--triage [--repo <tree>]]

/** every id at a block start: [{id, line}] (1-based) */
export function blockStarts(text) {
  const out = [];
  const lines = text.split("\n");
  let idCol = false;
  lines.forEach((l, i) => {
    if (/^\|/.test(l) && /^\|[\s:|-]+\|\s*$/.test(lines[i + 1] || "")) idCol = ID_COLS.has(l.split("|")[1].trim().toLowerCase());
    if (idCol && /^\|/.test(l)) { const m = l.match(ROW); if (m) for (const id of splitIds(m[1])) out.push({ id, line: i + 1 }); return; }
    for (const re of HEADS) {
      const m = l.match(re);
      if (m) { for (const id of splitIds(m[1])) out.push({ id, line: i + 1 }); break; }
    }
  });
  return out;
}

export function classify(body) {
  if (!BY_NAME) indexTree();

  const seen = new Set(); let best = "GONE";
  const rank = { LOCATABLE: 4, "FILE-ONLY": 3, MOVED: 2, AMBIGUOUS: 1, GONE: 0 };
  for (const c of cs) {

    if (rank[cl] > rank[best]) best = cl;

}

 * intake-triage.mjs — the MECHANICAL half of verifying an imported candidate register.
 *
 * WHY THIS EXISTS. `EXTERNAL-CANDIDATES-0002.md` holds 1,465 medium/low rows imported
 * UNVERIFIED from six external documents, at baselines that are not HEAD. Verifying them
 * the way INTAKE-0002 verified its 206 critical/high rows cost ~10.7k tokens per row;

 * 2,300 within-source and 3,500 cross-source near-file pairs).
 *
 * So the org does the free part first, in a script, with no rooms at all:
 *
 *   GONE       the cited file does not exist at HEAD. The row cannot be true as written.
 *   MOVED      the file exists but the cited line range is past its end — the code moved
 *              under the row. Its claim may still hold somewhere; its ADDRESS does not.

 *              whether the defect is real — only that a room would have somewhere to look.

 *              org tracks in REGISTRY.md or INTAKE-0001. It needs adjudication against
 *              that row, not fresh verification.
 *   NO-LOC     no parseable `path:line` in the location cell.
 *

 * and a MOVED row is not refuted — INTAKE-0002's own calibration is that a cheap room's
 * negative is wrong about two thirds of the time (the judge overturned 31 of 45, every
 * one a reinstatement), and a SCRIPT is cheaper than the cheapest room. What it buys is
 * the population: the rows worth paying a room to read, and the ones that cannot be right

/** A location cell may hold several `path:line` or `path:line-line` citations.
 *
 * MANY ROWS CITE A BARE FILENAME (`events.ts:118`), not a repo path. Resolving those
 * against the repo root is how the first cut of this script reported 165 rows GONE
 * whose files are plainly present one directory down — the same scan-boundary mistake
 * this org has now fixed in three other guards. So a bare name is RESOLVED against an
 * index of the tree, and a name that matches several files is reported as AMBIGUOUS
 * rather than silently bound to the first hit. */
function citations(cell) {
  const out = [];
  for (const m of cell.matchAll(/([A-Za-z0-9_@./-]+\.[A-Za-z0-9]+):(\d+)(?:-(\d+))?/g)) {
    out.push({ cited: m[1], from: Number(m[2]), to: m[3] ? Number(m[3]) : Number(m[2]) });
  }
  return out;
}

function indexTree() {
  // `org/` holds run scratch dirs with COPIES of source files (RUN-0003's pass4, the
  // harness placements). Indexing those makes an ordinary filename look ambiguous and
  // can bind a row to a copy nobody ships. The register cites PRODUCT code.
  // #297 (Wave B): `.scratch/` (a room's private working copy of files under attack, and this
  // very script's own test fixtures at tests/tooling/.scratch/tooling-test/) and `.stryker-tmp/`
  // (mutation-testing's own copy tree) hold COPIES of source files, same reasoning as `org/`
  // above -- indexing them lets an ordinary filename resolve ambiguously, or resolve to a stale
  // scratch copy instead of the real file the register actually cites.
  const skip = new Set(["node_modules", ".git", "dist", "coverage", ".wrangler", "org", ".scratch", ".stryker-tmp"]);
  const byName = new Map();
  const walk = (dir) => {
    for (const e of readdirSync(join(ROOT, dir), { withFileTypes: true })) {
      if (skip.has(e.name)) continue;
      const rel = dir ? `${dir}/${e.name}` : e.name;
      if (e.isDirectory()) walk(rel);
      else { const a = byName.get(e.name) ?? []; a.push(rel); byName.set(e.name, a); }
    }
  };
  walk("");
  return byName;
}

// are unreachable because their file IS drawn. A file list cannot express any of that.
//
// The extraction rule, stated so it can be disagreed with. A row is ADJUDICATED iff a
// room it was dispatched to wrote a verdict for it. Dispatch is read from the room's own
// `ROWS.md` (two historical shapes: `### ID (SRC, sev x)` from S-041 on, `- **ID** (SRC…)`

// Verdicts are then read from that room's `VERDICTS.md` by position, not by pattern: the
// id must appear in a verdict-bearing slot (a table's first cell, a bullet/bold lead, a
// heading) and the label is read from the field the room put beside it. Rooms used at
// least six incompatible layouts — three-column tables, four-column tables with a `limb`
// column, tables with no leading pipe, bullets, bare bold leads, and verdict-grouped
// headings — so the carrier is detected per line rather than assumed.
//
// Judge runs are NOT a separate closure route, which was worth establishing rather than
// assuming: all 239 ids ruled across JUDGE-0001..0006 had already been dispatched and
// already carried a room verdict. The judges are purely appellate. They are recorded here
// because 51 of them OVERTURNED the room, and a closure record that hid that would be
// telling the next wave a row is settled when its stated verdict has been reversed.
//

function carriers(line) {
  const out = [];
  const L = line.replace(/\u2011/g, "-");
  if (L.includes("|")) {
    const c = L.replace(/^\s*\|/, "").replace(/\|\s*$/, "").split("|");
    if (c.length >= 2) out.push({ kind: "table", lead: clean(c[0]), field: clean(c[1]) });
    // Four-column tables (AGENCYSESS, OPERATORUI, BUILDTRUTH, TOOLPROMISE) put an explicit
    // `limb` column between id and verdict; offer cell 2 as well and let the labels decide.
    if (c.length >= 3) out.push({ kind: "table4", lead: `${clean(c[0])} ${clean(c[1])}`, field: clean(c[2]) });
  }
  const m = L.match(/^\s*(?:[-*+]\s+|#{2,5}\s+)?(.{1,80}?)\s*(?:[\u2014\u2013]|--|\s:\s|:\s|\s-\s)\s*(.*)$/);
  if (m) out.push({ kind: "lead", lead: clean(m[1]), field: clean(m[2]) });
  return out;
}

// Ordered label rules, first match wins. `REAL` is tested before the closing verdicts
// because a room that writes "REAL — already fixed in part" is affirming the defect.
function classify(raw) {
  const t = (raw || "").toLowerCase().replace(/_/g, " ");
  if (!t) return null;
  const real = /\breal\b/.test(t);
  const ruled = /\bruled\b|\(decided\)|\bi decided\b|\bdecided:/.test(t);
  if (/\bnot located\b/.test(t)) return "NOT LOCATED";
  if (/\bcannot decide\b/.test(t)) return "CANNOT DECIDE";
  if (real && /\bwrong owner\b/.test(t)) return "REAL — WRONG OWNER";
  if (real && /(reported|not fixed here|not fixed\b|not built\b|not executable|\bblocked\b|out of (my|this room)|outside this room|cross-team|follow-up)/.test(t))
    return "REAL — REPORTED NOT FIXED";
  // _TALLY §1: a room that says it TOOK the ruling has ruled the row (JOBS2 SJ-16), and the
  // line is REAL rather than an open question handed back to the orchestrator.
  if (/\bneeds a ruling\b|\bneeds ruling\b/.test(t)) return ruled ? "REAL" : real ? "REAL — NEEDS A RULING" : "NEEDS A RULING";
  if (real) return "REAL";
  if (/\balready fixed\b/.test(t)) return "ALREADY FIXED";
  if (/\bnot a defect\b/.test(t)) return "NOT A DEFECT";
  if (/\binsufficient context\b|\bnot reproduced\b/.test(t)) return "INSUFFICIENT CONTEXT";
  if (/\bduplicate\b|\bdup of\b/.test(t)) return "DUPLICATE";
  return null;
}
// Roll a split row's limb lines up to one row verdict (_TALLY §1 precedence): if any limb
// is real the row's defect is in part real.
const PREC = ["REAL", "REAL — WRONG OWNER", "REAL — REPORTED NOT FIXED", "NEEDS A RULING",
  "CANNOT DECIDE", "NOT LOCATED", "ALREADY FIXED", "NOT A DEFECT", "INSUFFICIENT CONTEXT", "DUPLICATE"];
const fold = (v) => (v === "REAL — NEEDS A RULING" ? "NEEDS A RULING" : v);
const rollUp = (cs) => { const s = cs.map(fold); return PREC.find((p) => s.includes(p)) ?? s[0]; };

}

  if (/OVERTURNED|REJECTED/.test(t)) return "OVERTURNED";
  if (/NEEDS[_ ]REPRODUCTION/.test(t)) return "NEEDS REPRODUCTION";
  if (/CANNOT DECIDE/.test(t)) return "CANNOT DECIDE";
  if (/UPHELD|CONFIRMED/.test(t)) return "UPHELD";

  for (let i = 0; i < lines.length; i++) {
    const L = lines[i];
    // J2-CONSOLE groups rows under a verdict heading and gives each row only a title, so
    // the ruling is inherited from the section rather than written on the row's own line.
    const g = L.match(/^#{2,3}\s+\**(UPHELD-BUT-NARROWER|UPHELD|OVERTURNED|REJECTED|CANNOT DECIDE|NEEDS[_ ]REPRODUCTION)\**/i);
    if (g) { group = jClass(g[1]); continue; }

    // in its FIRST cell. The prior #279 fix widened the generic matchAll below to also accept `|`
    // as a separator so a table row's id would match at ALL — but that made it match ANY
    // registered id ANYWHERE on the line (including one merely MENTIONED in another row's own
    // "note"/"why" cell, e.g. "| F-3 | duplicate of E-11 | OVERTURNED |"), and jClass(clean(L))'s
    // whole-line fallback then handed THAT id the row's ruling too. A table row is now matched
    // structurally by its FIRST cell only, before any generic per-id scan ever sees the line.
    if (/^\s*\|/.test(L)) {
      const tm = L.match(new RegExp(String.raw`^\s*\|\s*(${ID})\s*\|(.*)$`));
      if (tm && regIds.has(tm[1])) {
        const cls = jClass(clean(tm[2])) || jClass(clean(L));
        if (cls && !judged.has(tm[1])) judged.set(tm[1], { ruling: cls, judge, source_file: f, line: i + 1 });
      }
      continue; // a table row is fully handled above — never fall through to the generic scan
    }
    // JUDGE-0005 writes rows as bold leads with no bullet: "**AA-04 — UPHELD.**"
    for (const m of L.matchAll(new RegExp(String.raw`(?:^|[^A-Z0-9-])(${ID})\s*(?:\([^)]*\))?\s*(?:[\u2014\u2013]|--|:)\s*([^|]{0,160})`, "g"))) {

      if (!cls && group && /^#{2,4}\s/.test(L)) cls = group;
      if (!cls) continue;

    }
  }
}

  // register holds twice that is not enough to say WHICH row was judged — AD-01 is ruled by
  // both JUDGE-0001 (S-037 scope, so the DR row) and JUDGE-0006 (S-056..061, so the CL row).
  // Rather than guess, an ambiguous id carries the ruling as unattributed.
  const j = judged.get(a.id);
  if (j) entry[idCount.get(a.id) > 1 ? "judge_unattributed" : "judge"] = { ruling: j.ruling, run: j.judge, source_file: j.source_file };
  if (!prev) { byKey.set(k, entry); continue; }
  // Same row ruled in two rooms. The later batch is operative; the earlier is kept, because
  // the pair is the most interesting thing this file records (see AS-082).
  const [older, newer] = prev.batch < a.batch ? [prev, entry] : [entry, prev];
  const merged = { ...newer, also: [...(prev.also ?? []), { verdict: older.verdict, batch: older.batch, room: older.room, source_file: older.source_file }] };
  // A JUDGE OVERTURNS A VERDICT, NOT A ROW (S-072). The ruling is indexed by bare id, so when
  // a row was ruled twice the overturn attaches to whichever entry happens to carry the id —
  // including the LATER one, which the judge never saw. `AS-082` is the worked example and it
  // nearly cost a second S-069: S-037 ruled it "NOT A DEFECT (for this file)", JUDGE-0001
  // overturned THAT, and S-071 then found it REAL and fixed it. Carrying the overturn forward
  // onto S-071's closure marks a fixed row as re-dispatchable, which is exactly the wasted
  // room the closure record exists to prevent — the same error in the opposite direction.
  //
  // So: an overturn whose judge run predates the operative closure is demoted to the `also`
  // entry it actually reviewed. The later verdict stands on its own merits, and the appellate
  // history is kept rather than deleted, because the pair is the most interesting thing this
  // file records. An overturn of the operative verdict is untouched and still reopens the row.
  const jr = merged.judge ?? merged.judge_unattributed;

    delete merged.judge; delete merged.judge_unattributed;
    merged.also = merged.also.map((x) => (x.batch === older.batch ? { ...x, judge: { ...jr, note: "overturned THIS verdict; superseded by the later ruling above" } } : x));
    merged.judge_superseded = true;
  }
  byKey.set(k, merged);
}

// Register text is quoted verbatim between `<<<FINDER` and `FINDER>>>` and nothing stopped

// read by the room, and by `quotedFinderSpans` above, as THIS SCRIPT's prose rather than as

// D-0419 names is real only for row ids, which finder prose can and does quote.
const ROW_HEAD_RE = /^\s*(?:[-*]\s*)?#{2,3}\s+\**\[?([A-Z]{1,6}-\d{1,4})\b[^\n]*\(/gm;
// S-086 (QUEUE #281): a header-shaped line INSIDE the finder's own quoted argument
// (<<<FINDER ... FINDER>>> / <<<FINDER-STUB ... FINDER-STUB>>>) is the finder's writing, not
// this wave's, and must never count as divergence — that quoting is verbatim by construction
// (renderRowBlock), so anything inside it is exactly as reliable, or unreliable, as the rest of
// the finder's prose the room is already told to read carefully. And where a match IS real (a
// row's own rendered block — its Title/Cited-at head, never finder-authored text — names an id
// this wave never emitted), the old code aborted the WHOLE wave with process.exit(1) before a
// single room's packet reached disk: one stray line failed every other room's turn too. The fix
// is scoped to the ROW the match came from: that row's block is dropped from its room (named on
// stderr, never silently), the rest of the room's rows and every other room still write. The
// run still signals the problem — process.exitCode is set to 1 at the very end, after writing —
// rather than aborting before anything lands.
// QUOTED_FINDER_RE is imported from scripts/lib/merged-rows.mjs (one copy, I19-FXD).
function quotedFinderSpans(text) {
  const spans = [];
  for (const m of text.matchAll(QUOTED_FINDER_RE)) spans.push([m.index, m.index + m[0].length]);
  return spans;
}
const insideAny = (spans, idx) => spans.some(([s, e]) => idx >= s && idx < e);
let divergenceFound = false;
function checkDivergence(built) {
  const emittedIds = new Set(built.flatMap((b) => b.rows.map((r) => r.id)));
  const out = [];
  for (const b of built) {
    const keptBlocks = [];
    const dropped = [];
    for (const blk of b.blocks) {
      const spans = quotedFinderSpans(blk.text);
      let badId = null;
      for (const m of blk.text.matchAll(ROW_HEAD_RE)) {
        if (insideAny(spans, m.index)) continue; // finder's own quoted prose — exempt
        if (!emittedIds.has(m[1])) { badId = m[1]; break; }
      }
      if (badId) dropped.push(`${blk.id} (names ${badId}, absent from this wave's emitted row list)`);
      else keptBlocks.push(blk);
    }
    if (dropped.length) {
      divergenceFound = true;
      process.stderr.write(`make-wave: PROSE/ROW-LIST DIVERGENCE in ${b.room} — ${dropped.length} row(s) dropped, not the whole wave:\n`);
      for (const d of dropped) process.stderr.write(`  ${d}\n`);
    }
    if (keptBlocks.length === 0) {
      if (b.blocks.length > 0) process.stderr.write(`make-wave: ${b.room} has no rows left after divergence filtering — room dropped.\n`);
      continue;
    }
    const keptIds = new Set(keptBlocks.map((x) => x.id));
    out.push({ ...b, rows: b.rows.filter((r) => keptIds.has(r.id)), blocks: keptBlocks });
  }
  return out;
}

// S-067: the extension list stopped at `.js`, so a row whose only citation was a `.kt` or a
// `.swift` path resolved to null and fell in with the rows that name no file at all. Forty-two
// of them did — the whole of both native clients — and they sat unrouted for the entire
// register while the notes recorded the located population as exhausted. This is the same
// shape as the KNOWN-REF hole S-066 found one layer up: a filter narrower than the thing it
// filters, silently dropping a population nobody was counting. The register's own `resolved`
// field, where an earlier pass computed one, is trusted ahead of the regex; failing that a
// bare or ellipsis-mangled path (`apps/android/.../ApiClient.kt`) is resolved by basename
// when exactly one file in the tree carries that name, and left null when several do.
const EXT = /`?([A-Za-z0-9_./-]+\.(?:ts|tsx|sql|mjs|js|kt|kts|swift))/;
let BASENAMES = null;
const byBasename = (p) => {
  if (!BASENAMES) {
    BASENAMES = new Map();
    const walk = (dir) => {
      for (const e of readdirSync(dir, { withFileTypes: true })) {
        if (e.name === "node_modules" || e.name === ".git" || e.name === "dist" || e.name === "build") continue;
        const full = `${dir}/${e.name}`;
        if (e.isDirectory()) walk(full);
        else {
          const k = e.name;
          if (!BASENAMES.has(k)) BASENAMES.set(k, []);
          BASENAMES.get(k).push(full.replace(/^\.\//, ""));
        }
      }
    };
    walk(".");
  }
  const hits = BASENAMES.get(p.split("/").pop()) ?? [];
  return hits.length === 1 ? hits[0] : null;
};
const fileOf = (r) => {
  if (r.resolved && existsSync(r.resolved)) return r.resolved;
  const raw = (r.location || "").match(EXT)?.[1] ?? null;
  if (!raw) return null;
  if (existsSync(raw)) return raw;
  return byBasename(raw);
};

// I3-0865 (W3-15-R3): the state filter was the ONE filter in this script that reported
// nothing. `reportClosure`, `reportHold` and `reportMultiArea` below all exist because a
// filter that shrinks a wave in silence reads as "the register is exhausted" — S-066's
// KNOWN-REF hole, S-067's extension list and S-072's file lock are three recorded instances

//
// The ROUTABLE column is the part that makes a state actionable rather than merely visible.
// `intake-triage.mjs` records no `resolved` for an AMBIGUOUS row (it is AMBIGUOUS precisely
// because the cited basename matched several files), so `fileOf` returns null for it and
// `--states=...,AMBIGUOUS` routes it nowhere: measured, 1 of 35. Printing the count a widened

// I3-0865's tally, CORRECTED (ORG-02-R2). `routable` counted `fileOf(r)` alone — the FIRST of
// the five predicates the selection loop below applies — and the line then reported that count as
// what widening WOULD ROUTE. Measured over the register at this commit: it promised 51 and

// are already adjudicated. The comment above states the intended property in its own words ("the
// count a widened `--states` would ACTUALLY route"), so this is the code not reaching its own
// stated bar, not a change of intent.
//
// The tally is built INSIDE reportStates() because the predicates it needs — CLOSED, citedAreas,
// hasExplicitMergedNote — are declared further down. reportStates is a hoisted declaration called
// at the very end, so by call time all of them are initialised. `closureOf` is deliberately NOT
// reused: it PUSHES to keptOverturned, which reportClosure prints, and reportStates runs one line
// BEFORE reportClosure — reusing it would make this report corrupt that one.
const widenOutcome = (r) => {
  const f = fileOf(r);
  if (!f) return "no file";
  if (HELD.has(f)) return "held";
  if (exclude.some((e) => f.includes(e))) return "excluded";
  const key = Object.hasOwn(CLOSED, `${r.id}@${r.source}`) ? `${r.id}@${r.source}`
    : Object.hasOwn(CLOSED, r.id) ? r.id : null;
  if (key) {
    const j = CLOSED[key].judge ?? CLOSED[key].judge_unattributed;
    if (j?.ruling !== "OVERTURNED") return "adjudicated";
  }
  const areas = citedAreas(r.location);
  if (areas.size > 1 && !hasExplicitMergedNote(r.id)) return "multi-area";
  return null;
};
function reportStates() {
  const w = (s) => process.stderr.write(`${s}\n`);
  w(`states: ROUTING ${STATES.join(",")} — ${work.length} of ${d.rows.length} row(s) are in these states.`);
  const stateDropped = new Map();
  for (const r of d.rows) {
    if (STATES.includes(r.state)) continue;
    const e = stateDropped.get(r.state) ?? { rows: 0, resolves: 0, routes: 0, blocked: new Map() };
    e.rows++;
    const why = widenOutcome(r);
    if (why !== "no file") e.resolves++;
    if (why === null) e.routes++;
    else if (why !== "no file") e.blocked.set(why, (e.blocked.get(why) ?? 0) + 1);
    stateDropped.set(r.state, e);
  }
  if (stateDropped.size === 0) { w("states: no row was dropped by the state filter."); return; }
  const total = [...stateDropped.values()].reduce((a, v) => a + v.rows, 0);
  const routes = [...stateDropped.values()].reduce((a, v) => a + v.routes, 0);
  w(`states: DROPPED ${total} row(s) whose triage state is not in --states; widening to every dropped state would route ${routes} of them. Widen with --states=${STATES.join(",")},<STATE>.`);
  for (const [st, e] of [...stateDropped].sort((a, b) => b[1].rows - a[1].rows || a[0].localeCompare(b[0]))) {
    const blocked = [...e.blocked].sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0])).map(([k, c]) => `${c} ${k}`).join(", ");
    w(`states:   ${String(e.rows).padStart(4)}  ${st.padEnd(10)}  ${e.resolves} of ${e.rows} resolve to a file; widening --states would ROUTE ${e.routes}`
      + (blocked ? ` (${blocked})` : "") + ".");
  }
}
// QUEUE #297a (D-0920 option 1, I16-W01F): the four UNROUTABLE states. A row whose citation did not
// resolve to one file (AMBIGUOUS: several files; GONE: none; NO-LOC: no location; ELIDED: a mangled
// path) can never reach a FILE room, so with the default --states it was dropped here every wave —
// counted by reportStates, routed nowhere. Each such row that is not already adjudicated is now
// EMITTED as a scout re-locate row (`<batch>/RELOCATE/ROWS.md` + `_relocate.json`); a row in these
// states that a widened --states DOES resolve to a file stays with the file router. Nothing is dropped
// in silence: the emitted and the adjudicated are both named on stderr.
const RELOCATE_STATES = ["AMBIGUOUS", "GONE", "NO-LOC", "ELIDED"];
function relocateSplit() {
  const emit = [];
  const closed = [];
  for (const r of d.rows) {
    if (!RELOCATE_STATES.includes(r.state)) continue;
    if (STATES.includes(r.state) && fileOf(r)) continue; // widened and resolvable: a file room takes it
    const key = Object.hasOwn(CLOSED, `${r.id}@${r.source}`) ? `${r.id}@${r.source}` : Object.hasOwn(CLOSED, r.id) ? r.id : null;
    const j = key ? (CLOSED[key].judge ?? CLOSED[key].judge_unattributed) : null;
    if (key && j?.ruling !== "OVERTURNED") closed.push(r);
    else emit.push(r);
  }
  return { emit, closed };
}

  const ids = (rows) => rows.map((r) => `${r.id}@${r.source}`).join(", ");
  w(`relocate: ${rel.emit.length} row(s) in unroutable states (${per(rel.emit)}) go to a SCOUT re-locate room${DRY ? " (dry run: nothing written)" : ` — org/07-findings/${batch}/RELOCATE/`}${rel.emit.length ? `: ${ids(rel.emit)}` : ""}.`);
  if (rel.closed.length) w(`relocate: ${rel.closed.length} row(s) in these states are already adjudicated and are not re-emitted: ${ids(rel.closed)}.`);
}

}
// #188 (QUEUE #188): the register's ids are how limbs get counted (ANTI-020's countermeasure
// is one CLAIMS entry per limb), and a row whose CITATIONS span more than one ownership area —
// "area" is a cited path's first two segments, e.g. `services/trust-core` vs `apps/web` vs
// `packages/schema` — hands one room a defect it owns at most half of before the room even
// starts. AG-03 (a console purgeUrl escaping gap packaged with an unrelated `agency_members.ts`
// rowid-reuse finding under one id) is the worked example this row named. A row's own
// `location` string cites the SECOND file bare when it sits beside the first ("a.ts:1;
// b.ts:2" means b.ts is in a.ts's directory) — this resolves that elision before comparing
// areas, so two files that really are siblings never look like a false multi-area citation.
// P2-I2 (REG S-081 phase 2): a fixed source-extension list meant a row citing
// apps/web/index.html (or any .md/.css/.toml/.yaml/.sh/... file) alongside a real code
// citation in a different area was invisible to this check -- ONE area seen, routed to a
// single room, even though the citations really span two. Any `path.ext` citation counts now,
// not just a maintained whitelist of code extensions.
const CITE_EXT_RE = /([A-Za-z0-9_./-]+\.[A-Za-z][A-Za-z0-9]{1,8})\b/g;
// The area is the DIRECTORY's first two segments (services/trust-core, apps/web, packages/i18n,
// migrations, ...), never the filename — a bare top-level file has no directory and is its own
// area. Computed on the directory, not the raw path, so two siblings in a one-segment directory
// (migrations/0002_x.sql and an elided migrations/0003_y.sql) read as the SAME area instead of
// looking like two different ones because slicing the whole path happened to keep the filename.
function areaOf(fullPath) {
  const dirParts = fullPath.split("/").slice(0, -1);
  return dirParts.length === 0 ? fullPath : dirParts.slice(0, 2).join("/");
}
function citedAreas(location) {
  const areas = new Set();
  let lastDir = null;
  for (const seg of (location || "").split(/[;,]/)) {
    for (const raw of seg.match(CITE_EXT_RE) ?? []) {
      const p = raw.includes("/") ? raw : lastDir ? `${lastDir}/${raw}` : raw;
      if (raw.includes("/")) lastDir = raw.split("/").slice(0, -1).join("/");
      if (p.includes("/")) areas.add(areaOf(p));
    }
  }
  return areas;
}

  const i = argv.indexOf("--budget-ms");

  const v = argv[i + 1];
  if (v === undefined || !/^\d+$/.test(v)) usage(`--budget-ms needs a whole number of milliseconds — got: ${JSON.stringify(v)}`);
  return Number(v);
}
// Writes the index entries git has not marked skip-worktree (`ls-files -t` tag H), from meta.checkout.done on, a chunk
// at a time, until all are written or the budget is spent. Records progress in the sidecar after every chunk.
function checkoutChunks(meta, budget, t0) {
  const paths = gitIn(meta.path, ["ls-files", "-t", "-z"]).split("\0").filter((e) => e.startsWith("H ")).map((e) => e.slice(2));
  meta.checkout = { done: Math.min(meta.checkout?.done ?? 0, paths.length), total: paths.length };
  writeFileSync(sidecarPath(meta.room), JSON.stringify(meta, null, 2) + "\n");
  while (meta.checkout.done < paths.length) {
    if (Date.now() - t0 >= budget) return false;
    const chunk = paths.slice(meta.checkout.done, meta.checkout.done + CHECKOUT_CHUNK);
    gitIn(meta.path, ["checkout-index", "-f", "-z", "--stdin"], { input: chunk.join("\0") + "\0" });
    meta.checkout.done += chunk.length;
    writeFileSync(sidecarPath(meta.room), JSON.stringify(meta, null, 2) + "\n");
  }
  return true;
}
function finishAdd(meta, budget, t0) {
  if (!checkoutChunks(meta, budget, t0)) {
    console.error(`partial: worktree '${meta.room}' has ${meta.checkout.done} of ${meta.checkout.total} file(s) written after ${Date.now() - t0} ms; continue with: node scripts/intake/room-worktree.mjs add ${meta.room} --resume`);
    process.exit(PARTIAL_EXIT);
  }
  const linked = linkNodeModules(meta.path);
  meta.complete = true;
  writeFileSync(sidecarPath(meta.room), JSON.stringify(meta, null, 2) + "\n");
  return linked;
}

function requireRoom(room) {
  if (!room || !ROOM_RE.test(room)) usage(`ROOM must match ${ROOM_RE} — got: ${JSON.stringify(room)}`);
}
function sidecarPath(room) {
  return join(WT_DIR, `${room}.json`);
}
function worktreePath(room) {
  return join(WT_DIR, room);
}

// Every apps/*, services/*, packages/* dir that already has its own node_modules in ROOT, plus
// ROOT's own node_modules — the full set a pnpm workspace hoists into, per package.
function nodeModulesTargets() {
  const targets = [];
  if (existsSync(join(ROOT, "node_modules"))) targets.push("node_modules");
  for (const cat of ["apps", "services", "packages"]) {
    const catDir = join(ROOT, cat);
    if (!existsSync(catDir)) continue;
    for (const entry of readdirSync(catDir, { withFileTypes: true })) {
      if (!entry.isDirectory()) continue;
      const nm = join(cat, entry.name, "node_modules");
      if (existsSync(join(ROOT, nm))) targets.push(nm);
    }
  }
  // I46-FXR-TOOLS (D-1307 F9; I46-RG-TOOLS NEW-03): plus each EXACT member pnpm-workspace.yaml lists (a nested one such as
  // services/image/embedder, which the one-level scan above never reaches) that holds a node_modules. An absolute or `..` entry
  // is skipped; a glob or negated entry names no directory, so it links nothing; a member listed twice is linked once
  // (linkNodeModules skips a dest that exists).
  const ws = join(ROOT, "pnpm-workspace.yaml");
  if (existsSync(ws)) {
    for (const m of readFileSync(ws, "utf8").matchAll(/^\s*-\s+["']?([^"'\s]+)["']?(?:\s+#.*)?\s*$/gm)) {
      if (m[1].startsWith("/") || /(^|\/)\.\.(\/|$)/.test(m[1])) continue;
      const nm = join(m[1], "node_modules");
      if (existsSync(join(ROOT, nm))) targets.push(nm);
    }
  }
  return targets;
}

// I46-TOOLS (I46-SCOUT-B/FINDINGS.jsonl:83 SCB-083; I45-TE-DRAFT-07): a package's node_modules holds RELATIVE links into the
// workspace (`@dhwaja/legal -> ../../../../packages/legal`). Linked whole, such a dir resolves them from the BUILD tree's
// location, so a worktree ran the build tree's packages. A node_modules with a relative link (top level or one @scope deep)
// whose target leaves it is therefore rebuilt in the worktree entry by entry (mirrorNodeModules); any other stays one link.
function escapesNodeModules(nmRoot, dir = nmRoot) {
  return readdirSync(dir, { withFileTypes: true }).some((e) => {
    const p = join(dir, e.name);
    if (e.isSymbolicLink()) {
      const t = readlinkSync(p);
      return !isAbsolute(t) && relative(nmRoot, resolve(dirname(p), t)).startsWith("..");
    }
    return e.isDirectory() && e.name.startsWith("@") && escapesNodeModules(nmRoot, p);
  });
}
// Each relative link is re-created with its own text, so it resolves inside the worktree; every other entry is linked to the
// build tree's entry; an @scope dir is rebuilt the same way.
function mirrorNodeModules(src, dest) {
  mkdirSync(dest, { recursive: true });
  for (const e of readdirSync(src, { withFileTypes: true })) {
    const s = join(src, e.name);
    if (e.isSymbolicLink() && !isAbsolute(readlinkSync(s))) symlinkSync(readlinkSync(s), join(dest, e.name));
    else if (e.isDirectory() && e.name.startsWith("@")) mirrorNodeModules(s, join(dest, e.name));
    else symlinkSync(s, join(dest, e.name));
  }
}

function linkNodeModules(wtPath) {
  const linked = [];
  for (const rel of nodeModulesTargets()) {
    const dest = join(wtPath, rel);
    if (existsSync(dest)) continue; // already there (shouldn't be, but never clobber)
    mkdirSync(join(dest, ".."), { recursive: true });
    if (escapesNodeModules(join(ROOT, rel))) mirrorNodeModules(join(ROOT, rel), dest);
    else symlinkSync(join(ROOT, rel), dest, "dir");
    linked.push(rel);
  }
  return linked;
}

// The repo's own `.gitignore` has `node_modules/` (dir-only), which does NOT match a SYMLINK
// named node_modules -- and this tool links, never copies, node_modules into a worktree. Left
// alone, `git status` (and a room's own `git add -A`) sees each node_modules symlink as an
// ordinary untracked path: `remove`'s dirty check false-refuses a clean worktree, and a room
// committing inside its worktree would commit the symlink into its own history, which `merge`
// would then cherry-pick into the shared build tree (observed: a first version of this tool did
// exactly that in testing -- the merge diff-stat carried `node_modules | 1 +`). `.git/info/exclude`
// is local-only (never committed) and shared by every worktree of this repo -- one type-agnostic
// `node_modules` line here closes the gap for all of them without touching the tracked `.gitignore`.
function ensureNodeModulesExcluded(repoDir = ROOT) {
  // Isolated clones have their OWN .git (own git-common-dir), separate from ROOT's — this must run
  // against that clone's own exclude file, not ROOT's, or its node_modules symlinks show dirty.
  const commonDir = gitIn(repoDir, ["rev-parse", "--git-common-dir"]).trim();
  const excludePath = join(repoDir, commonDir, "info/exclude");
  mkdirSync(join(excludePath, ".."), { recursive: true });
  const existing = existsSync(excludePath) ? readFileSync(excludePath, "utf8") : "";
  if (!existing.split("\n").includes("node_modules")) {
    writeFileSync(excludePath, existing + (existing === "" || existing.endsWith("\n") ? "" : "\n") + "node_modules\n");
  }
}

function cmdResume(room, budget, t0) {
  const wtPath = worktreePath(room);
  if (!existsSync(sidecarPath(room)) || !existsSync(wtPath)) usage(`refused: --resume needs a worktree and its sidecar for '${room}' under ${WT_DIR}`);
  const meta = JSON.parse(readFileSync(sidecarPath(room), "utf8"));
  if (!meta.checkout || meta.complete === true) usage(`refused: '${room}' has no unfinished checkout to resume`);
  const linked = finishAdd(meta, budget, t0);
  console.log(`added worktree '${room}' at ${wtPath} (base ${meta.base.slice(0, 12)}), ${linked.length} node_modules symlink(s), resumed to ${meta.checkout.done} of ${meta.checkout.total} file(s)${meta.sparse === false ? ", sparse-checkout FAILED (see the warning above)" : ""}`);
}

function cmdAdd(argv) {
  const t0 = Date.now();
  const room = argv[0];
  requireRoom(room);
  const budget = budgetMs(argv);
  if (argv.includes("--resume")) return cmdResume(room, budget, t0);
  const isolated = argv.includes("--isolated");
  const refIdx = argv.indexOf("--ref");
  const ref = refIdx >= 0 ? argv[refIdx + 1] : (isolated ? null : git(["rev-parse", "HEAD"]).trim());
  const wtPath = worktreePath(room);
  if (existsSync(wtPath)) usage(`refused: ${wtPath} already exists — remove it first or pick another ROOM`);
  mkdirSync(WT_DIR, { recursive: true });
  let base, linked;
  let sparse = isolated ? null : true;
  if (isolated) {
    // D-0424.3 / #278 item 5: a shallow, single-branch CLONE (its own .git, not a worktree of
    // ROOT's) — only the objects reachable from <ref>'s tip are transferred, so `git diff`/`git
    // log` inside it can never reach master or any other branch (unlike `worktree add`, which
    // shares ROOT's object store and every ref). For read-only attack/judge rooms only — see
    // cmdMerge below, which refuses to merge an isolated room back.
    if (!ref) usage("--isolated needs --ref <branch>");
    try { git(["rev-parse", "--verify", "--quiet", `refs/heads/${ref}`]); }
    catch { usage(`refused: --isolated needs an existing branch — refs/heads/${ref} not found`); }
    git(["clone", "--quiet", "--no-local", "--depth", "1", "--single-branch", "--no-tags", "--branch", ref, ROOT, wtPath]);
    // P2-S2 (REG phase 2, D-0424.3 item 5): --single-branch/--depth only bound the INITIAL fetch —
    // the clone's `origin` remote still points at ROOT, so a room could `git fetch origin master`
    // (or any other ref) after the clone and read it anyway. Remove the remote entirely: no remote,
    // no fetch target, and `git for-each-ref` then lists only the one local branch this clone has.
    gitIn(wtPath, ["remote", "remove", "origin"]);
    ensureNodeModulesExcluded(wtPath);
    base = gitIn(wtPath, ["rev-parse", "HEAD"]).trim();
    linked = linkNodeModules(wtPath);
  } else {
    ensureNodeModulesExcluded(ROOT);
    base = git(["rev-parse", ref]).trim();
    // --no-checkout: nothing is written here, so a cut-off call cannot leave a half-written index (I40TER-TREE).
    git(["worktree", "add", "--no-checkout", "--detach", wtPath, base]);
    // Sparse-checkout state lives in the per-worktree index, so this touches ONLY this worktree.
    // I37TE-03: on a mount that refuses unlink, sparse-checkout fails; the worktree still gets its
    // node_modules links (nodeModulesTargets) and the run says so, instead of exiting 1 without them.
    try {
      gitIn(wtPath, ["sparse-checkout", "init", "--no-cone"]);
      gitIn(wtPath, ["sparse-checkout", "set", "/*", "!/repomix-output.xml"]);
    } catch (e) {
      sparse = false;
      const why = String(e.stderr || e.message || e).trim().split("\n").pop();
      console.error(`warning: sparse-checkout failed in ${wtPath} (${why}); repomix-output.xml may be checked out and git may hide paths it marked skip-worktree. node_modules links are made anyway.`);
    }
    // The index is filled from base without touching the work tree; reapply then marks the sparse-excluded paths
    // skip-worktree (it writes no file into an empty tree), and checkoutChunks writes the rest.
    gitIn(wtPath, ["read-tree", base]);
    if (sparse) gitIn(wtPath, ["sparse-checkout", "reapply"]);
  }
  const meta = { room, path: wtPath, base, ref, isolated, sparse, createdAt: new Date().toISOString() };
  if (!isolated) {
    // An isolated clone writes its tree in `git clone` and has no `checkout` field, so --resume refuses it.
    meta.checkout = { done: 0, total: null };
    meta.complete = false;
    linked = finishAdd(meta, budget, t0);
  }
  writeFileSync(sidecarPath(room), JSON.stringify(meta, null, 2) + "\n");
  console.log(`added ${isolated ? "isolated clone" : "worktree"} '${room}' at ${wtPath} (base ${base.slice(0, 12)}), ${linked.length} node_modules symlink(s)${sparse === false ? ", sparse-checkout FAILED (see the warning above)" : ""}`);
}

function cmdList() {
  const raw = git(["worktree", "list", "--porcelain"]);
  const blocks = raw.split("\n\n").filter(Boolean);
  const rows = [];
  for (const b of blocks) {
    const pathM = b.match(/^worktree (.+)$/m);
    const headM = b.match(/^HEAD (.+)$/m);
    if (!pathM) continue;
    const p = resolve(pathM[1]);
    if (!p.startsWith(WT_DIR + "/")) continue;
    const room = p.slice(WT_DIR.length + 1);
    let meta = null;
    if (existsSync(sidecarPath(room))) {
      try { meta = JSON.parse(readFileSync(sidecarPath(room), "utf8")); } catch { /* leave null */ }
    }
    rows.push({ room, path: p, head: headM ? headM[1] : null, base: meta?.base ?? null, createdAt: meta?.createdAt ?? null });
  }
  if (rows.length === 0) { console.log("no room worktrees under .scratch/wt/"); return; }
  for (const r of rows) console.log(`${r.room}\t${r.head?.slice(0, 12) ?? "?"}\tbase=${r.base?.slice(0, 12) ?? "?"}\t${r.path}`);
}

function cmdRemove(argv) {
  const room = argv[0];
  requireRoom(room);
  const force = argv.includes("--force");
  const wtPath = worktreePath(room);
  if (!existsSync(wtPath)) usage(`refused: no worktree '${room}' at ${wtPath}`);
  const meta = existsSync(sidecarPath(room)) ? JSON.parse(readFileSync(sidecarPath(room), "utf8")) : null;
  // --force discards whatever is there, so the dirty listing is read only when it can refuse (F-I40INV-10).
  const dirty = force ? "" : gitIn(wtPath, ["status", "--porcelain"]).trim();
  if (dirty && !force) {
    console.error(`refused: worktree '${room}' has uncommitted changes (--force to discard them):`);
    console.error(dirty);
    process.exit(1);
  }
  if (meta?.isolated) {
    // An isolated clone is not registered as a worktree of ROOT — `git worktree remove` would
    // fail (not found); it is its own self-contained .git, so deleting the directory is enough.
    rmSync(wtPath, { recursive: true, force: true });
  } else {
    const args = ["worktree", "remove"];
    if (force) args.push("--force");
    args.push(wtPath);
    git(args);
    try { git(["worktree", "prune"]); } catch { /* best effort */ }
  }
  if (existsSync(sidecarPath(room))) rmSync(sidecarPath(room));
  console.log(`removed ${meta?.isolated ? "isolated clone" : "worktree"} '${room}'`);
}

function cmdMerge(argv) {
  const room = argv[0];
  requireRoom(room);
  const wtPath = worktreePath(room);
  if (!existsSync(wtPath)) usage(`refused: no worktree '${room}' at ${wtPath}`);
  if (!existsSync(sidecarPath(room))) usage(`refused: no sidecar metadata for '${room}' at ${sidecarPath(room)} — was it added by this tool?`);
  const meta = JSON.parse(readFileSync(sidecarPath(room), "utf8"));
  if (meta.isolated) {
    console.error(`refused: '${room}' is an isolated clone (read-only attack/judge work) — merge is not supported for isolated rooms`);
    process.exit(1);
  }
  const base = meta.base;
  const head = gitIn(wtPath, ["rev-parse", "HEAD"]).trim();
  if (base === head) {
    console.log(`nothing to merge: worktree '${room}' HEAD equals its base ${base.slice(0, 12)}`);
    return;
  }
  const diffStat = git(["diff", "--stat", `${base}..${head}`]);
  console.log(diffStat);
  const commits = gitIn(wtPath, ["rev-list", "--reverse", `${base}..${head}`]).trim().split("\n").filter(Boolean);
  if (commits.length === 0) {
    console.log(`nothing to merge: no commits reachable from ${head.slice(0, 12)} that aren't from ${base.slice(0, 12)}`);
    return;
  }
  const preHead = git(["rev-parse", "HEAD"]).trim();
  try {
    git(["cherry-pick", ...commits]);
  } catch (e) {
    // Leave nothing half-applied: abort any in-progress pick, then hard-reset to exactly where
    // the build tree was before this merge started, discarding any commit this same invocation
    // DID manage to apply before the conflict.
    try { git(["cherry-pick", "--abort"]); } catch { /* nothing in progress to abort */ }
    git(["reset", "--hard", preHead]);
    console.error(`refused: cherry-pick conflict merging '${room}' — build tree HEAD restored to ${preHead.slice(0, 12)}, nothing applied.`);
    console.error(e.message ?? String(e));
    process.exit(1);
  }
  const newHead = git(["rev-parse", "HEAD"]).trim();
  console.log(`merged '${room}': applied ${commits.length} commit(s), build tree HEAD ${preHead.slice(0, 12)} → ${newHead.slice(0, 12)}`);
}

else if (cmd === "remove") cmdRemove(rest);
else if (cmd === "merge") cmdMerge(rest);
else usage(cmd ? `unknown subcommand: ${cmd}` : "a subcommand is required");
